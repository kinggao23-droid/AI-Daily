## 1. 今日要闻

### 要闻一：AWS Bedrock AgentCore 发布 Agent 性能优化套件（Preview）

**平台**：AWS Bedrock AgentCore

**更新内容**：2026年5月中旬，Amazon Bedrock AgentCore 推出性能优化三件套（Preview）：
1. **Recommendations**：基于运行时遥测自动生成 Agent 性能改进建议（如工具选择优化、prompt 精简方向）
2. **Batch Evaluations**：支持批量测试集离线评估，量化 Agent 在多轮对话场景下的准确率与一致性
3. **A/B Tests**：内置流量分割与统计显著性判定，可在生产环境中对比不同 Agent 配置的效果

三项能力组成完整的「观测→评估→改进」闭环。同期，AgentCore 还扩展至巴西圣保罗区域和 GovCloud（US-West），并新增自定义 Header 透传功能。

**影响分析**：此前 Agent 优化需借助 Braintrust、Arize 等第三方平台。AWS 将评估和 A/B 测试内置于 AgentCore，直接挤压了独立 LLMOps 工具的市场空间。对已在 AWS 生态的企业来说，减少了一个外部采购决策。

**参考链接**：[AWS 官方公告](https://aws.amazon.com/about-aws/whats-new/2026/05/bedrock-agentcore-optimization-preview/) | [AWS 周报 May 11](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-amazon-bedrock-agentcore-payments-agent-toolkit-for-aws-and-more-may-11-2026/)

### 要闻二：Bedrock AgentCore Payments 进入预览——AI Agent 首次拥有「钱包」

**平台**：AWS Bedrock AgentCore

**更新内容**：AgentCore 联合 Coinbase 和 Stripe 推出 Agent 支付能力（Preview）。AI Agent 可自主完成：
- 访问并付费调用外部 API / MCP Server
- 钱包身份验证与交易执行
- 预算上限与支出治理
- 完整支付审计追踪

这是业界首个为自主 Agent 设计的托管支付基础设施。

**影响分析**：Agent 从「只能回答问题」进化到「可以花钱办事」，是 Agentic AI 商业化的里程碑。企业需重新思考 Agent 的权限治理——不仅是「能说什么」，还有「能花多少」。对产品经理而言，这打开了「Agent-as-a-Service」的新商业模式设计空间。

**参考链接**：[AWS AgentCore Payments 公告](https://aws.amazon.com/about-aws/whats-new/2026/04/amazon-bedrock-agentcore-payments-preview/)

### 要闻三：百度文心 ERNIE 5.1 正式发布——预训练成本降至行业 6%

**平台**：百度智能云（文心大模型）

**更新内容**：百度文心团队 2026年5月发布 ERNIE 5.1，核心突破：
- **架构**：超稀疏 MoE，总参数从前代 2.4T 压缩至约 0.8T（减少 2/3）
- **激活参数**：约 36B（前代减半）
- **预训练成本**：仅为同规模模型的 6%
- **训练方法**：分散式完全异步强化学习 + 大规模 Agent 后训练

**影响分析**：ERNIE 5.1 的核心叙事是「用 6% 的成本达到同等性能」。对国内企业客户而言，这直接影响千帆平台的推理定价——成本降低意味着 API 调用价格有进一步下探空间。在「价格战」白热化的国内市场，这是百度的成本结构优势。

**参考链接**：[ERNIE Blog](https://ernie.baidu.com/blog/) | [知乎技术解读](https://zhuanlan.zhihu.com/p/2003784708518082128)

## 5. 对产品经理的启示

### 1. Agent 经济体系正在形成——提前规划治理框架

AWS AgentCore Payments 的推出意味着 Agent 不再只是「对话工具」，而是可以执行交易的经济主体。产品经理应开始设计：
- Agent 预算审批流程（谁授权、上限多少）
- 支出可追溯性要求（审计合规）
- 失控场景的熔断机制

### 2. 云厂商「全家桶」策略加速——独立工具的窗口期在缩短

AWS 将评估/A/B 测试内置于 AgentCore，Snowflake 将 Guardrails 扩展至全平台。独立 LLMOps 工具（Braintrust、Arize、Langfuse）的差异化窗口正在收窄。选型建议：
- 若已深度绑定某云生态 → 优先用原生工具，减少集成成本
- 若多云/混合部署 → Langfuse（开源自托管）或 Braintrust（SaaS）仍有不可替代价值

### 3. 国内市场进入「成本效率」决胜阶段

ERNIE 5.1 用 6% 成本达到前代水平，腾讯混元 Hy3 以 210 亿激活参数撬动 2950 亿总参。国内平台的竞争叙事已从「谁更大」转向「谁更省」。对企业选型意味着：
- 关注 token 单价的实际下降趋势，不急于签长期合约
- 阿里 5/20 万亿 Token 活动是试用窗口，可借此做基准测试

### 4. 可观测性正在成为基础设施标配

vLLM 0.21.0 原生 OTel 支持 + Snowflake 全平台 Guardrails + Databricks AI Gateway 观测增强——可观测性不再是「锦上添花」，而是生产部署的准入条件。建议将 trace/eval/guardrails 纳入技术选型的必选项清单。
