### 1.1 Apple WWDC 2026：Siri 重生，开放第三方 AI 市场（6月8日）

**发生了什么**：Apple 在 WWDC 2026 主题演讲中发布重构版 Siri，云端智能由 Google 定制的约 1.2 万亿参数 Gemini 模型驱动，Apple 每年向 Google 支付约 10 亿美元。更重要的是，iOS 27 推出 **Extensions 框架**，用户可在设置中将 Claude、ChatGPT、Gemini 或 Grok 设为默认 AI，覆盖 Siri、写作工具、图像创作等所有 Apple Intelligence 功能。

**影响分析**：这是 LLMOps 领域的分水岭事件。Apple 将 AI 模型选择权交给用户，意味着：

- **Anthropic 和 OpenAI 获得了绕过云厂商直达消费者的新通道**

## 4. 新兴平台雷达

### 4.1 🆕 Snowflake CoCo — 数据平台跨界 AI 编程 Agent

Snowflake 将 Cortex Code 重新品牌为 CoCo，定位为"数据原生 AI 编程 Agent"。与 GitHub Copilot/Cursor 不同，CoCo 在生成代码前自动读取 Snowflake 的 Schema、权限策略和数据血缘，适合数据工程场景。支持桌面端、Cloud Agents（后台异步执行）和 Skill Catalog（团队共享工作流）。**值得关注原因**：这是数据平台厂商首次将 AI 编程 Agent 作为一级产品发布。

### 4.2 🆕 Databricks Agent Bricks — 自动化 Agent 构建

Databricks 推出 Agent Bricks，用户只需提供任务描述和企业数据，平台自动生成合成训练数据、任务基准测试，并优化成本-质量平衡。**值得关注原因**：将 Agent 构建从"手动调 prompt + 评估"简化为"描述任务 → 自动优化"，可能改变 LLMOps 的工作流范式。

### 4.3 🆕 Laminar — LLM 可观测性新挑战者

在 Langfuse vs LangSmith 的对比中，Laminar 作为新兴竞品被多次提及。定位是轻量级 LLM 可观测性平台，主打对比分析能力。

### 4.4 🆕 Unravel Data — Databricks/Snowflake/BigQuery 自动优化引擎

5月27日发布自主优化引擎，可自动优化 Databricks、Snowflake 和 BigQuery 上的 AI 工作负载成本和性能。**值得关注原因**：随着企业 AI 支出增长，第三方成本优化工具可能成为新细分赛道。

## 5. 对产品经理的启示

### 5.1 "Agent 控制平面"之争已经开始——选型窗口正在收窄

Snowflake（CoWork/CoCo）、Databricks（Agent Bricks/Genie）、Microsoft（Copilot）、Google（Gemini Enterprise）都在争夺"企业 AI Agent 的控制层"。如果你的企业数据主要在 Snowflake 上，CoWork/CoCo 是阻力最小的 Agent 化路径；如果在 Databricks 上，Agent Bricks 的自动优化能力值得 POC。**建议**：在 Q3 之前完成至少一个 Agent 平台的 POC，避免在生态锁定后被动迁移。

### 5.2 Apple 开放 AI 选择权，To-C 影响将传导至 To-B

iOS 27 的 Extensions 框架意味着普通用户将开始"比较"不同 AI 模型。当员工在个人设备上习惯了 Claude 或 ChatGPT，他们会对企业内部 AI 工具产生更高期望。**建议**：密切关注 Apple Extensions 的采用数据（预计 7 月公测），将其作为终端用户 AI 偏好的早期指标。

### 5.3 "廉价 AI"时代并未到来——模型成本分化加剧

Gemini 3.5 Flash 定价是前代的 3 倍（$1.50/$9 per 1M tokens），但阿里云 Qwen3.5 低至 0.8 元/百万 tokens（约 $0.11）。国际模型在涨价，国内模型在补贴式降价。**建议**：对于延迟不敏感的批处理场景（文档分析、数据标注），评估国内模型（通过百炼 API 或火山引擎方舟）的成本优势，可能节省 10-15 倍成本。

### 5.4 开源推理引擎持续进化，自建推理的 ROI 在改善

vLLM v0.22.1 的 MRv2 在 GB200 上实现 56% 吞吐提升，DeepSeek V4 获得全面优化支持。对于推理量大（>100M tokens/天）的企业，自建推理集群 + vLLM 的经济性越来越好。**建议**：如果月度模型 API 账单超过 $50,000，启动自建推理的 TCO 对比分析。

### 5.5 LLMOps 可观测性工具链趋于成熟，该选了

Braintrust（$80M 融资、$8 亿估值）、Langfuse（开源、自托管）、LangSmith（LangChain 生态绑定）三强格局基本形成。Braintrust 率先支持 GPT-5.5 Pro 和 Workload Identity Federation，安全合规能力领先；Langfuse 是自托管和隐私敏感场景的首选。**建议**：如果还没有部署 LLM 可观测性工具，Q3 是合适的评估窗口——工具已成熟，但尚未出现垄断性锁定。
