## 1. 今日要闻

### 1.1 华为 HDC 2026 发布 HarmonyOS 7 + 盘古大模型 6.0 端侧部署

**平台：华为云盘古**

华为开发者大会（HDC 2026）于 6 月 12-14 日在东莞松山湖举行，发布五大核心成果：

- **HarmonyOS 7**：系统内核原生集成盘古大模型 6.0，AI 任务可完全在设备端离线运行，数据不出端
- **鸿蒙智能体框架 2.0（Harmony Intelligence Framework 2.0）**：支持系统级 Agent 架构，智能助手小艺升级为系统级 Agent
- **openPangu 2.0 开源**：盘古大模型首次面向开发者开源
- 鸿蒙生态已聚合超 **1100 万注册开发者**，应用市场提供超 **40 万**应用和服务

**影响分析：** 盘古 6.0 端侧部署是国内大模型厂商中首个系统级原生集成方案。对企业客户意味着：(1) 数据隐私合规天然满足——数据不离开设备；(2) 离线场景可用——适合制造业、矿山等网络受限场景。openPangu 2.0 开源则降低了企业二次开发门槛。

### 1.2 AWS Bedrock 正式上线 OpenAI GPT-5.5 / GPT-5.4 / Codex

**平台：AWS Bedrock**

自 6 月 1 日起，OpenAI 旗舰模型在 Amazon Bedrock 全面可用（GA）：

| 模型 | 定位 | 可用区域 | 定价（输入） |
|------|------|----------|-------------|
| GPT-5.5 | 最强前沿模型，深度推理/编程/Agent | US East (Ohio) | 与 OpenAI 官方一致，无额外费用 |
| GPT-5.4 | 最佳性价比 | US East (Ohio), US West (Oregon), GovCloud | 与 OpenAI 官方一致 |
| Codex | 编程 Agent | US East (Ohio) | 与 OpenAI 官方一致 |

关键细节：
- 这是 OpenAI **结束与微软独家云协议后**的首次多云落地
- 用量可计入 AWS 消费承诺（EDP/Commit）
- 同期，AWS 还新增了 Mistral、Google、NVIDIA、MiniMax、Moonshot、Qwen 等模型

**影响分析：** Bedrock 的"模型超市"策略进一步巩固——企业无需切换云平台即可使用 OpenAI 模型，且消费可纳入现有 AWS 合同。对已有 AWS 架构的企业来说，迁移成本几乎为零。

> 参考：[AWS 官方博客](https://aws.amazon.com/blogs/aws/get-started-with-openai-gpt-5-5-gpt-5-4-models-and-codex-on-amazon-bedrock/) | [AboutAmazon](https://www.aboutamazon.com/news/aws/bedrock-openai-models)

### 1.3 Snowflake Summit 2026：CoWork + CoCo 重塑 Agent 企业控制面

**平台：Snowflake Cortex**

Snowflake Summit 2026（6 月 1-4 日）发布 26+ 项新能力，两大核心产品完成品牌重塑：

| 原名 | 新名 | 定位 | 新增能力 |
|------|------|------|----------|
| Snowflake Intelligence | **CoWork** | 知识工作者个人 Agent | Deep Research、可复用 Artifacts、用户记忆、定时自动化、移动端 App、Slackbot |
| Cortex Code | **CoCo** | 开发者 AI 编程 Agent | 桌面 App（持久项目上下文）、VS Code 扩展、Claude Code 插件、多 Agent 编排 |

同期定价调整：
- **Cortex AI_TRANSCRIBE 降价 60%**：统一定价 $0.35/小时音频（此前 Standard $0.47、Enterprise $0.70、Business Critical $0.94）
- **Cortex AI_COMPLETE 新增 Gemini 3.5 Flash 支持**：支持多模态视频/音频分析

**影响分析：** Snowflake 的战略意图清晰——从"数据仓库"转向"Agent 企业控制面"。CoWork 让业务人员直接用自然语言操作治理数据，CoCo 让开发者在数据平台内构建 AI 管道。对数据团队来说，这意味着 LLMOps 能力正在被嵌入到数据基础设施中，而非作为独立工具存在。

## 4. 新兴平台雷达

### 4.1 🆕 Snowflake CoWork / CoCo

虽然 Snowflake 本身不是新公司，但 CoWork 和 CoCo 作为全新产品线值得关注。它们代表了一种趋势：**数据基础设施平台正在内嵌 LLMOps 能力**，而非让企业单独采购 LLMOps 工具。如果你的数据已在 Snowflake 中，这可能是阻力最小的 Agent 开发路径。

### 4.2 🆕 Inception Labs（扩散式 LLM）

Palo Alto 初创公司，由 Stanford 教授 Stefano Ermon 领衔，已获 $5000 万种子轮（Menlo Ventures 领投，NVIDIA NVentures、Microsoft M12、Snowflake Ventures、Databricks 跟投，Andrew Ng 和 Andrej Karpathy 天使参投）。

核心技术：**扩散式大语言模型（dLLM）**——借鉴图像生成原理，不逐字生成而是并行生成整段回复，速度提升 10 倍。旗舰模型 Mercury 是全球首个商用 dLLM。

**为什么值得关注：** 如果 dLLM 技术成熟，将从根本上改变推理成本结构，对 vLLM 等推理引擎和所有按 token 计费的平台产生深远影响。

### 4.3 🆕 Microsoft Foundry Local Agents

Build 2026 推出的新能力（Public Preview），可以发现和管理本地运行的 AI Agent（如 Claude Code、GitHub Copilot CLI），统一纳入 Foundry 的治理和可观测性框架。这代表了一种新趋势：**云平台开始管理边缘/本地 Agent**。

## 5. 对产品经理的启示

### 5.1 "模型超市"格局已定，选平台比选模型更重要

AWS Bedrock 同时提供 OpenAI、Claude、Llama、Mistral、Qwen 等 30+ 模型；Microsoft Foundry 也接入了 GPT-5.5 和 Claude。**模型之间的能力差距已缩小到 5-15%**，真正影响企业选型的是合规、数据驻留、定价和生态集成。

**建议：** 评估平台时，优先看 (1) 你现有的云合同和消费承诺（EDP），(2) 数据驻留和合规要求，(3) 已有技术栈的集成深度。模型可以随时切换，平台迁移成本高得多。

### 5.2 Agent 记忆和治理成为新战场

Microsoft Foundry 的 Memory Toolkit + Toolboxes、Snowflake 的 CoWork 用户记忆、华为的端侧 Agent 框架——三家同时在 Agent 的"记忆"和"工具治理"方向发力。这意味着 **Agent 正在从 demo 走向生产**，记忆持久化和工具权限管控是关键卡点。

**建议：** 如果你的产品路线图包含 Agent 能力，现在就应该评估"Agent 记忆如何持久化"和"Agent 调用外部工具时权限如何管控"这两个架构问题。

### 5.3 腾讯混元迁移窗口——检查你的依赖

腾讯混元 46 个旧版模型将于 **6 月 22 日下线**（距今仅 7 天）。如果你的产品或内部系统使用了 hunyuan-turbos、hunyuan-t1 等旧版模型，必须立即启动迁移至 TokenHub 平台的 hy3-preview 版本。

**建议：** 本周内排查所有调用腾讯混元 API 的服务，确认模型版本，制定迁移计划。hy3-preview 采用 295B/21B MoE 架构，256K 上下文，性能有提升但 API 接口可能有变化。

### 5.4 端侧大模型值得关注

华为盘古 6.0 原生集成到 HarmonyOS 7 的做法表明，**端侧大模型部署正在从实验走向量产**。对于数据敏感行业（金融、医疗、政务）和网络受限场景（制造业、矿山），这是一个值得纳入技术选型的方案。

### 5.5 Google Vertex AI 模型折旧——注意迁移时间线

Gemini 2.0 Flash 已于 6/1 关闭，Imagen 全系将于 6/24 关闭，多个 preview 模型 6/25 关闭。如果你使用 Google Vertex AI，务必检查模型版本并升级到 Gemini 3.5 Flash 或更新版本。
