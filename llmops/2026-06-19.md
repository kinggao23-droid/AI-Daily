### 要闻一：AWS Summit 纽约 2026 — Bedrock 迎来三大升级

**平台：AWS Bedrock**

6月18日，AWS 在纽约峰会上发布多项 Bedrock 重大更新：

1. **Amazon Bedrock AgentCore 正式 GA**：一个全托管的 AI Agent 运行环境，无需编码即可在分钟级别构建生产级 AI Agent。可以理解为"AI Agent 的云端工厂"——企业不再需要自己搭建复杂的基础设施，直接在 Bedrock 上点几下就能让 Agent 跑起来。
2. **Bedrock 上线 OpenAI 模型（受限预览）**：GPT-5.5 和 GPT-5.4 现可通过 Bedrock Managed Agents 使用，这意味着企业可以在 AWS 的安全环境中同时使用 Claude、Llama 和 OpenAI 模型，无需分别对接各家 API。
3. **Gemma 4 系列模型上架**：Google DeepMind 的 Gemma 4 三个版本（31B / 26B-A4B MoE / E2B）已在 Bedrock 可用。
4. **Web Search 工具集成**：为 AgentCore 新增全托管 Web 搜索能力，Agent 可以基于实时网页信息回答问题，且数据不出客户的 AWS 安全边界。

**影响分析**：AWS 将"模型超市"策略推向极致——一个平台上集齐 Claude + OpenAI + Gemma + Llama，企业选型不再需要"站队"。AgentCore GA 则降低了 Agent 开发门槛，直接对标 Google 的 Agent Platform。
