# LLMOps 竞品情报日报

**日期**：2026-06-20（周六）

**概要**：本周是 LLMOps 领域的高密度发布周。AWS Summit New York（6/17-19）带来 Bedrock 多项重磅更新；华为 HDC 2026（6/12）发布开源盘古 2.0；OpenAI 模型正式在 Bedrock GA；Langfuse 发布 AI SDK v7 beta 支持。以下为近期关键动态汇总。

## 1. 今日要闻

### 要闻一：AWS Summit New York 发布 Bedrock 三大新能力

**平台**：AWS Bedrock / AgentCore

**时间**：2026-06-17 至 06-19

**具体更新**：

1. **Bedrock Managed Knowledge Base**：全托管知识库服务，内置数据连接器、Smart Parsing（自动多格式文档解析）和 Agentic Retriever（多步骤复杂查询检索器），与 AgentCore Gateway 原生集成。相比此前需要手动配置向量数据库 + 嵌入模型 + 分块策略的 Knowledge Base，新版只需点击几步即可完成从数据摄入到检索的全流程。（可以理解为：以前搭 RAG 像自己组装家具，现在 AWS 直接送"成品家具"上门。）

2. **Web Search on AgentCore**：全托管 Web 搜索工具，让 Agent 能在零数据出境的前提下获取实时互联网信息，返回经重排序的最新网页结果。开发者无需额外集成第三方搜索 API。

3. **AgentCore 生产监控增强**：新增故障定位和控制策略能力，帮助团队在生产环境中发现并修复 Agent 运行问题，同时在 Agent 能力增长时自动扩展治理控制。

**影响分析**：AWS 正在将 Bedrock 从"模型调用平台"升级为"企业 Agent 全生命周期平台"。Managed Knowledge Base 显著降低了企业 RAG 的实施门槛，直接对标 Azure Foundry IQ 和 Google Vertex AI 的 RAG 能力。Web Search 能力让 Bedrock Agent 在信息时效性上追上了 Google 的优势领域。

### 要闻二：OpenAI GPT-5.5 / GPT-5.4 / Codex 在 Amazon Bedrock 正式 GA

**平台**：AWS Bedrock × OpenAI

**时间**：2026-06-11 起陆续 GA

**具体更新**：

- **GPT-5.5**（OpenAI 最强模型）和 **GPT-5.4** 现已在 Bedrock US East (N. Virginia) 区域正式可用，支持 Responses API
- **Codex**（OpenAI 编程 Agent）同步上线，采用按 Token 计费（无席位费）
- 定价与 OpenAI 官方一致，用量可计入 AWS 消费承诺（committed spend）
- Console 支持即将上线

**影响分析**：这是 AWS 与 OpenAI 扩大合作的标志性事件。企业客户现在可以在 Bedrock 统一平台上同时使用 Claude、GPT-5.5、Llama 等模型，并享受 AWS IAM/CloudTrail 等企业级治理能力。对于已有 AWS 消费承诺的客户，使用 OpenAI 模型的边际成本几乎为零。这进一步巩固了 Bedrock "模型超市"的定位。

### 要闻三：华为发布开源盘古 openPangu 2.0，余承东宣布全面开源计划

**平台**：华为云盘古

**时间**：2026-06-12（HDC 2026）

**具体更新**：

| 版本 | 总参数量 | 激活参数量 | 上下文长度 |
|------|----------|------------|------------|
| openPangu 2.0 Pro | 505B | 18B | 512K |
| openPangu 2.0 Flash | 92B | 6B | 512K |

- 采用 MoE 架构，针对昇腾算力深度优化，单卡吞吐率达主流开源模型 2 倍
- 适配鸿蒙系统，Agent 任务执行"更快更准更省"
- **6 月 30 日起陆续开源 7 大组件**：预训练代码、后训练代码、训推算子等
- 余承东发言："全世界都不知道大模型是何物的时候，华为就发布了盘古大模型。我的字典里没有第二，只有第一。"

**影响分析**：华为首次将盘古大模型大规模开源，505B 参数量在国内开源模型中属于第一梯队。昇腾算力优化是核心差异点——在美国芯片禁令背景下，华为提供了一条不依赖 NVIDIA GPU 的替代路径。但开源代码尚未正式发布（6/30 才开始），实际性能需要社区验证。

## 4. 新兴平台雷达

### 🆕 Snowflake CoWork / CoCo（原 Snowflake Intelligence / Cortex Code）

Snowflake 在 Summit 2026（6/1-4）完成重大品牌重塑：
- **CoWork**：面向知识工作者的个人 AI Agent（原 Snowflake Intelligence）
- **CoCo**：编程 Agent（原 Cortex Code），现已支持跨平台数据系统（AWS Glue、Databricks、Postgres）
- **Cortex Sense**：底层上下文引擎，自动从查询历史、元数据、BI 定义中构建共享上下文层
- **AI Agent Identity**（GA）：为每个 Agent 提供加密身份、细粒度 RBAC 和完整审计链

**关注理由**：Snowflake 正在从"数据仓库"转型为"数据驱动的 Agent 平台"。对于以 Snowflake 为数据底座的企业，这可能成为比独立 LLMOps 平台更自然的选择。

### 🆕 Google Gemini Enterprise Agent Platform（原 Vertex AI）

Google 已将 Vertex AI 服务整合进全新的 **Gemini Enterprise Agent Platform**，新能力不再以 Vertex AI 更新的形式发布。关键变化：
- Gemini 3.5 Flash 自 6/8 起默认开启且不可关闭
- Project Mariner 实验终止，浏览能力整合进 Gemini Agent 和 AI Mode
- Vertex AI Python SDK 旧模块迁移截止日：**2026-06-24**
- gemini-3.1-flash-image-preview 等旧模型 **6/25 下线**

**关注理由**：Google 的品牌整合表明 Gemini 正在成为 Google Cloud AI 的统一入口，Vertex AI 作为独立品牌逐渐淡化。产品经理在做选型对比时需注意品牌名变化。

### 🆕 Microsoft Foundry Agent 发布能力（原 Azure AI Foundry）

Build 2026 后的关键新能力：
- Agent 直接发布到 **Teams 和 M365 Copilot**（6 月 GA）
- **程序性记忆**（Procedural Memory）：Agent 跨运行学习如何执行任务，早期 benchmark 显示任务成功率提升
- **Foundry IQ**：升级为知识平面，含 Serverless 检索、Web IQ、安全更新
- **Fireworks AI 入驻 Foundry**：更多推理选择

### 🆕 Laminar（LLM 可观测性新玩家）

在 2026 年初发表了与 Langfuse / LangSmith 的对比文章，定位为 LLM 可观测性领域的替代方案。值得持续关注其产品差异化策略。

## 5. 对产品经理的启示

### 5.1 Agent 平台成为核心战场

AWS、Azure、Google、Databricks、Snowflake 五大平台在 6 月集中发力 **Agent 基础设施**（记忆、工具调用、知识检索、身份治理）。这意味着：

- **选型建议**：2026 下半年的平台选型，应优先评估 Agent 全生命周期能力（构建→测试→部署→监控→治理），而非仅看模型调用 API
- **行动项**：梳理自身产品的 Agent 场景需求，对照上述功能对比表做差距分析

### 5.2 "模型超市"格局确立

AWS Bedrock 同时提供 Claude + GPT-5.5 + Llama + Mistral，Azure Foundry 也类似。这意味着：

- **模型锁定风险降低**：企业可以在同一平台上灵活切换模型，无需绑定单一供应商
- **行动项**：产品架构应设计为模型无关（Model-Agnostic），通过统一 API 层接入多模型，便于根据成本/性能/合规需求灵活切换

### 5.3 国内开源竞争加剧

华为 openPangu 2.0（505B）、腾讯混元 Hy3（295B）、阿里 Qwen3.7-Max 三大模型在 4-6 月密集发布。对于国内产品经理：

- **昇腾适配是差异点**：如果企业面临 GPU 供应限制，华为盘古 + 昇腾路线值得评估
- **行动项**：对 Qwen3.7-Max 的限时半价活动（截至 6/22）进行成本测算，评估是否值得迁移部分工作负载

### 5.4 可观测性不可忽视

Langfuse 本周发布 AI SDK v7 beta 和 MCP 管理评估器，Braintrust 提供评估到发布的全流程闭环。随着 Agent 复杂度提升，可观测性将从"可选"变为"必选"。

- **行动项**：如果团队尚未部署 LLM 可观测性工具，建议从 Langfuse（开源、支持自部署）开始试点，再评估商业方案

### 5.5 关注平台品牌重塑

Google（Vertex AI → Gemini Enterprise Agent Platform）和 Snowflake（Intelligence → CoWork, Cortex Code → CoCo）的品牌变更反映了产品战略转型。产品经理在阅读文档和做竞品分析时需注意名称变化，避免信息遗漏。
