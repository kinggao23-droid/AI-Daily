### 🔥 要闻一：火山引擎发布豆包 2.1 Pro，Coding/Agent/VLM 三项能力对标 Claude Opus 4.6，定价仅为其 20%

**平台**：火山引擎（字节跳动）

**核心数据**：
- **日均 Token 调用量**：突破 **180 万亿**，过去一年增长超 10 倍

- **定价**：每百万 Tokens 输入 **6 元**、输出 **30 元**，综合使用成本较 Claude Opus 4.6 降低近 **80%**

**影响分析**：火山引擎以接近五成的国内 MaaS 市场份额和极具攻击性的定价策略，正在快速建立规模效应。豆包 2.1 Pro 将 Claude Opus 4.6 作为对标对象，表明国内顶级模型在 Coding 和 Agent 场景的能力已进入同一竞技场。对于成本敏感的企业用户，火山引擎的性价比优势极为突出。

### 🔥 要闻二：Seltz 完成 $1,250 万种子轮融资，为 AI Agent 构建全新搜索基础设施

**平台**：🆕 Seltz（新发现平台）

6月24日，AI 基础设施初创公司 Seltz 宣布完成 $1,250 万种子轮融资，由 Speedinvest 和 B Capital 联合领投，Bain & Company 旗下 Future Back Ventures、Italian Founders Fund、United Ventures 参投。

**核心信息**：
- **定位**：为 AI Agent 重建 Web 搜索引擎——传统搜索引擎面向人类的短关键词查询设计，Seltz 面向 Agent 的长精确查询和并行搜索需求
- **性能**：每天爬取数亿网页，响应延迟低于 **200 毫秒**
- **差异化**：不返回整页内容或摘要，而是评分到段落级别，精准提取 Agent 所需的特定表格、文本或图像
- **团队规模**：仅 15 人（6 名全职），2025 年 10 月成立
- **行业意义**：Agent 搜索基础设施是 LLMOps 生态中尚未被充分解决的关键层——当前 Agent 依赖传统搜索 API（Google/Bing），存在延迟高、信息冗余、不支持机器可读引用等问题

**影响分析**：随着 Agent 工作流成为主流（Deloitte 预测 2027 年 50% 使用生成式 AI 的企业将部署 Agent），为 Agent 优化的搜索层将成为刚需。Seltz 的出现标志着 LLMOps 生态正在向更深的基础设施层延伸。

> 参考：[Fortune 独家报道](https://fortune.com/2026/06/24/exclusive-seltz-a-startup-rebuilding-web-search-for-ai-agents-raises-12-5-million-in-seed-funding/) · [SiliconANGLE](https://siliconangle.com/2026/06/24/agentic-infrastructure-startup-seltz-raises-12-5m-help-ai-agents-search-web-answers/) · [Unite.AI](https://www.unite.ai/seltz-raises-12-5-million-seed-round-to-build-a-new-search-infrastructure-layer-for-ai-agents/)

### 🔥 要闻三：腾讯混元大规模下线 46 个旧版本模型，Hy3 混合专家模型全面接棒

**平台**：腾讯混元

腾讯云于 6 月 22 日正式下线原混元大模型平台 HY2.0、hunyuan-turbos、hunyuan-t1 等 **46 个旧版本模型**，推动用户全面迁移至新一代 Hy3 模型。

**Hy3 核心规格**：
- **架构**：快慢思考融合的混合专家模型（MoE）
- **总参数**：**295B**，激活参数 **21B**
- **最大上下文**：**256K** tokens
- **能力提升**：复杂推理、指令遵循、上下文学习、代码、Agent 等全面提升

**影响分析**：一次性下线 46 个旧模型是国内云平台中罕见的大规模模型整合动作，显示腾讯正在精简模型矩阵、集中资源在 Hy3 上建立竞争力。295B 总参 / 21B 激活的 MoE 架构在推理效率上具有优势，但 256K 的上下文窗口相比竞品（Qwen 支持 100 万、盘古支持 512K）仍有差距。企业用户需注意迁移适配工作。

## 4. 新兴平台雷达

### 🆕 Seltz——AI Agent 专用搜索引擎

**背景**：美国注册公司，2025 年 10 月成立，15 人团队，$1,250 万种子轮（Speedinvest + B Capital 领投，Bain 旗下 Future Back Ventures 参投）。

**技术创新**：传统搜索引擎（Google、Bing）为人类设计——用户输入短关键词，浏览链接列表。AI Agent 的搜索模式完全不同：发送长精确查询，需要机器可读的结构化信息和可引用的来源。通俗比喻：传统搜索像在图书馆找书，Seltz 像一个替你翻到具体段落并划出重点的研究助理。

**性能指标**：日爬取数亿网页，响应延迟 <200ms，支持段落级精准提取。

**关注理由**：随着 Agent 工作流（Databricks Agent Bricks、Dify、Langfuse 等）成为主流，Agent 搜索基础设施将成为关键依赖层。目前 Agent 普遍使用 Google/Bing Search API，存在延迟高、结果冗余、不支持结构化引用等痛点。Seltz 的出现预示着 LLMOps 生态将沿基础设施纵深方向持续扩展。

> 参考：[Fortune](https://fortune.com/2026/06/24/exclusive-seltz-a-startup-rebuilding-web-search-for-ai-agents-raises-12-5-million-in-seed-funding/)

## 5. 对产品经理的启示

### 1. 国内 MaaS 市场格局正在固化——火山引擎以 49.5% 份额领跑

火山引擎凭借豆包大模型的调用量优势和激进定价策略，已在国内公有云 MaaS 市场建立近半壁江山。**建议**：如果你的企业主要面向国内市场，火山引擎是绕不开的第一评估对象。但需注意"半价促销"等活动的时效性——促销期结束后的常规定价才是长期成本基准。

### 2. 华为 openPangu 2.0 开源在即（6/30），信创场景迎来重要选项

华为计划 6 月 30 日开源 openPangu 2.0 的七大组件（预训练代码、后训练代码、推理代码等），且该模型针对昇腾芯片优化，单卡吞吐率达业界主流开源模型的 **2 倍**。**建议**：对有国产芯片适配要求的信创项目、政企客户，openPangu 2.0 将是最重要的候选——它是目前唯一在昇腾+麒麟全栈上深度优化的开源大模型。建议提前安排技术团队关注 6/30 开源发布。

### 3. Agent 搜索基础设施正在成为新的竞争层

Seltz 的 $1,250 万种子轮融资表明，投资人已开始押注 Agent 生态的"基础设施纵深"——不仅是 Agent 框架和可观测性，连 Agent 依赖的搜索引擎都在被重新设计。**建议**：在规划 Agent 产品的工具链时，将搜索能力纳入评估维度。当前基于 Google/Bing API 的搜索方案可能无法满足高频 Agent 调用的延迟和结构化需求。

### 4. 模型下线迁移需纳入平台选型考量

腾讯一次性下线 46 个旧版模型的做法提醒企业：**模型生命周期管理**是平台选型中容易被忽视的关键维度。**建议**：在选型时明确询问平台的模型下线通知周期、迁移支持工具、API 向后兼容策略。避免因模型突然下线导致业务中断。

### 5. 6 月开源大爆发创造了模型评估窗口

NVIDIA Nemotron 3 Ultra、智谱 GLM-5.2、华为 openPangu 2.0 等重磅开源模型集中释放，为企业提供了难得的横向对比窗口。**建议**：趁 6 月底至 7 月初的密集开源期，组织技术团队在企业实际场景（而非通用 benchmark）上进行 A/B 测试，产出内部模型选型报告。开源模型的私有化部署在数据安全和成本可控性上具有天然优势。
