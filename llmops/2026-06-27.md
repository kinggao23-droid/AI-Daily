### 🔥 要闻一：AWS 纽约峰会密集发布——Bedrock Managed Knowledge Base GA、AgentCore Web Search、Grok 4.3 上线

**平台**：AWS Bedrock / AgentCore

AWS 于 6 月 17-22 日纽约峰会期间集中发布了多项 Bedrock 重磅功能，本周陆续 GA：

**① Bedrock Managed Knowledge Base（全托管知识库）**
- **定位**：将企业 RAG 管道从"自建"变为"全托管"——数据接入、解析、向量化、检索一站完成
- **6 个原生连接器**：Amazon S3、SharePoint、Confluence、Google Drive、OneDrive、Web Crawler，支持自动增量同步与托管向量存储
- **Smart Parsing**：自动处理 PDF 表格、扫描件、PPT 等多格式文档，无需预处理
- **Agentic Retriever**：对复杂多跳查询自动拆分子问题、多次检索后综合回答

**② AgentCore Web Search（Agent 联网搜索）**
- Agent 可在全托管环境中检索实时网页信息，所有数据不出 AWS 安全边界
- 返回结果附带引用链接，支持 Grounding 验证

**③ Grok 4.3（xAI）上线 Bedrock**
- 6 月 15 日 GA，100 万 token 上下文，最大输出 30,000 token
- 定价 $1.25（输入）/ $2.50（输出）每百万 token——Bedrock 上最便宜的前沿推理模型
- 直接与 Claude、GPT-5.5 在同一平台竞争

**④ OpenAI GPT-5.5 / GPT-5.4 / Codex 全面 GA**
- 6 月 1 日起 GA，6 月 11 日扩展至 US East (N. Virginia)
- 定价与 OpenAI 官方一致，用量可计入 AWS 合约承诺额度
- Codex 编程 Agent 每周超过 400 万开发者使用

**影响分析**：AWS 正在将 Bedrock 从"模型超市"升级为"全托管 Agent 操作系统"——知识库、联网搜索、安全护栏、上下文服务一体化。对于已在 AWS 生态的企业，Managed Knowledge Base 将显著降低 RAG 方案的建设门槛，从原来需要 LangChain + Pinecone + 自建 ETL 的组合，简化为单一 API 调用。

vLLM 在 6 月连续发布多项重要更新：

**② Semantic Router v0.3 Themis（6 月 5 日）+ Fusion 路由（6 月 16 日）**
- 从信号感知升级为"有状态生产路由"：根据请求复杂度、成本预算、延迟要求，将推理请求智能分发到最优模型

**影响分析**：vLLM 正从"单模型高性能推理引擎"进化为"多模型智能调度平台"。Semantic Router 的成熟意味着企业可以在一个推理集群内混合部署不同规模的模型（如 70B + 7B），让路由层自动选择最优模型处理每个请求，在性能和成本之间取得最佳平衡。

- **短期**：如果你的产品还在用 LangChain + Pinecone + 自建 ETL 搭建 RAG，现在可以评估迁移到云平台的全托管方案，节省 2-3 人的维护成本
- **中期**：RAG 能力将成为"水电煤"般的基础设施，竞争焦点转向数据质量和业务逻辑层
