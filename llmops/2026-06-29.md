### 🔥 要闻一：OpenAI 发布 GPT-5.6 Sol / Terra / Luna 三模型系列，引入"Ultra 多智能体"模式

**平台**：OpenAI

**具体内容**：6月26日，OpenAI 发布 GPT-5.6 系列三款模型，采用限量预览方式（约 20 家经政府审批的企业可使用），计划数周内扩展至广泛可用：

| 模型 | 定位 | 关键特点 |

- **Max 推理模式**：给予 Sol 最长推理时间，用于深度复杂任务

### 🔥 要闻二：OpenAI GPT-5.5 / GPT-5.4 / Codex 正式 GA 上线 Amazon Bedrock

**平台**：AWS Bedrock × OpenAI

**具体内容**：6月中旬，OpenAI 旗下 GPT-5.5、GPT-5.4 和 Codex 在 Amazon Bedrock 正式全面可用（General Availability）。这是 OpenAI 首次将旗舰模型上架非自有平台，定价与 OpenAI 一方 API 一致，用量可计入 AWS 消费承诺（EDP/PPA）。

| 模型 | 用途 | 可用区域 |
|------|------|---------|
| GPT-5.5 | 旗舰：编码、研究、长程 Agent 任务 | US East (N. Virginia) |

**影响分析**：这打破了"OpenAI = 闭环生态"的固有认知。AWS 客户现可通过统一的 Bedrock API 同时调用 Claude、GPT、Llama、Mistral 等模型，且用量均计入 AWS 消费承诺。对产品经理而言，Bedrock 正在成为真正的"模型超市"——选模型不再等于选平台。Codex 转向按 Token 计费对高频调用场景可能更有利，建议重新评估编码 Agent 成本模型。
