## 1. 今日要闻（3 条重大更新）

### 🔥 要闻一：华为 openPangu 2.0 今日启动开源，7 大组件陆续释出

**平台**：华为云盘古

**具体内容**：6月30日起，华为正式启动 openPangu 2.0 的开源计划，陆续释出 7 大组件，包括此前未公开的预训练代码、后训练代码和训练算子。这批组件是对 6月12日华为开发者大会（HDC 2026）上发布的开源盘古 2.0 模型的重要补充。

openPangu 2.0 模型规格：

| 版本 | 总参数量 | 激活参数量 | 上下文窗口 | 定位 |
|------|---------|-----------|-----------|------|
| **Pro** | 5050 亿（505B） | 180 亿（18B） | 512K | 旗舰，复杂推理与长文本 |
| **Flash** | 920 亿（92B） | 60 亿（6B） | 512K | 轻量高速，端侧适配 |

今日新开源的组件（稠密模型系列）：
- **盘古 7B**：70 亿参数稠密模型
- **盘古 Pro MoE 72B**：720 亿参数混合专家模型

技术亮点：模型在昇腾硬件上做了深度优化，官方称单卡吞吐率可达业界主流开源模型的 2 倍。余承东表示华为更聚焦推理时延和吞吐率的提升，而非单纯堆参数。

**影响分析**：openPangu 2.0 的开源对国产 LLMOps 平台意义重大——它是首个同时开放预训练代码 + 后训练代码 + 训练算子的国产大模型。对依赖昇腾芯片的企业（尤其政企客户），这提供了完整的"国产芯片 + 国产模型 + 开源训练栈"方案，直接挑战 DeepSeek、Qwen 在开源生态中的先发优势。但 505B 总参数相比竞品偏小，余承东坦言"自己留的算力有限"。

### 🔥 要闻二：Gemini 3.5 Pro 确认延期至 7 月，Google 未兑现 I/O 承诺

**平台**：Google Vertex AI

**具体内容**：6月30日——Google I/O 2026（5月19日）上 Sundar Pichai 承诺的"下个月"交付 Gemini 3.5 Pro 的最后期限已到。截至今日，Gemini 3.5 Pro 仍处于有限 Vertex AI 预览阶段，未向公众开放。多家媒体确认发布已推迟至 2026 年 7 月。

Gemini 3.5 Pro 预期规格：
- **上下文窗口**：200 万 tokens（2M），为 Flash 的 2 倍，当前所有生产级前沿模型之最
- **推理能力**：配备 Deep Think 深度推理模式
- **定位**：Google 最强推理模型，对标 Claude Opus / GPT-5.5 Sol

与此同时，**Gemini 3.5 Flash** 已于 5月19日 GA 并全面投入生产，API 定价 $1.50/$9.00 每百万 tokens（输入/输出），在编码和 Agent 基准测试中以约 4 倍速度超越 Gemini 3.1 Pro。

**影响分析**：Gemini 3.5 Pro 的延期给竞品留出窗口期。Claude Opus 4.6/4.8 和 GPT-5.6 Sol 在旗舰市场暂无新的 Google 挑战者。对于使用 Vertex AI 的企业客户，建议暂用 Gemini 3.5 Flash 作为过渡方案，其 1M 上下文和快速推理在多数生产场景已够用。

### 🔥 要闻三：腾讯混元 HY2.0 旧模型今日下线，平台 9 月底全面停服

**平台**：腾讯混元

**具体内容**：2026年6月22日起（本周持续生效），腾讯云正式下线原腾讯混元大模型平台 HY2.0 等 46 个旧版本模型。原混元大模型平台将于 2026年9月30日全面停服。

这意味着腾讯将混元生态全面迁移至新一代 **Hy3 架构**：

| 项目 | Hy3 规格 |
|------|---------|
| 架构 | 快慢融合 MoE（192 路专家 + top-8 路由） |
| 总参数 | 295B |
| 激活参数 | 21B |
| 上下文窗口 | 256K |
| MTP 层参数 | 3.8B |
| 重点能力 | 复杂推理、指令遵循、代码、Agent |

**影响分析**：46 个旧模型集中下线意味着腾讯在做一次"断舍离"——减少模型碎片化，集中资源在 Hy3 架构上竞争。对正在使用混元 HY2.0 的企业客户，迁移窗口仅剩 3 个月（截至 9月30日），建议尽快启动迁移测试。

- **融资**：种子轮 $1250 万（6月24日）
- **投资方**：Speedinvest（欧洲）+ B Capital（全球）领投，Bain & Company 旗下 Future Back Ventures 参投
- **定位**：为 AI Agent 和聊天机器人重新构建搜索引擎，挑战 Google 在 Agent 搜索场景的统治地位
- **关注理由**：随着 Agentic AI 成为 2026 年主旋律，Agent 需要专门的信息检索基础设施。AWS Bedrock AgentCore 已内置 Web Search 工具，Seltz 瞄准的是更通用的独立搜索层

### 🆕 Databricks Omnigent — 元编排框架

- **发布**：DAIS 2026
- **定位**：Databricks 自研的 meta-harness（元编排框架），同时支持 LangGraph、CrewAI、Agno、Claude Code SDK、OpenAI Agent SDK 等多框架
- **关注理由**：标志着大厂平台从"选一个框架"走向"兼容所有框架"，可能压缩独立 Agent 编排框架的生存空间

### 🆕 Snowflake Cortex Sense — 运行时上下文增强

- **发布**：Snowflake Summit 2026（6月初）
- **定位**：自动为 AI 查询注入企业上下文，将结构化数据问答准确率从 ~24% 提升至 ~86%
- **关注理由**：解决了"模型能力强但不懂企业数据"的核心痛点，与 Databricks Unity Catalog 的治理+语义层形成差异化竞争

## 5. 对产品经理的启示

### 5.1 华为开源 = 国产替代方案再添选项

openPangu 2.0 开源训练全栈（预训练代码 + 后训练代码 + 训练算子）是国产大模型的首次。对政企客户：
- **立即行动**：如果团队使用昇腾芯片，今日起可开始评估 openPangu 2.0 的 7B 稠密模型和 72B MoE 模型，作为 DeepSeek/Qwen 之外的第三选项
- **注意风险**：505B 总参数规模偏小，在通用 benchmark 上可能不及 Qwen-Max 或 DeepSeek V4，需结合具体场景测试

### 5.2 Gemini 3.5 Pro 延期 = 选型窗口延长

对正在评估 Vertex AI 的团队：
- **短期**：继续使用 Gemini 3.5 Flash（$1.50/$9.00 per M tokens），在速度和成本上已优于 Gemini 3.1 Pro
- **不要等**：如果核心需求是旗舰推理能力，Claude Opus 和 GPT-5.5 已经 GA，无需押注 Gemini 3.5 Pro 的不确定时间表

### 5.3 Agent 平台进入"兼容一切"阶段

Databricks Agent Bricks 支持 6+ 框架、AWS Bedrock AgentCore 支持 MCP、Dify 新增 MCP 客户端、TrueFoundry 推出 MCP Gateway——2026 年 Q2 的主题是 **互操作性**：
- **选型建议**：不再需要因框架绑定而选择平台。选择标准应回归数据治理（Unity AI Gateway vs. Bedrock Guardrails vs. Snowflake Horizon）和已有云基础设施
- **MCP 是新标准**：所有主要平台均已支持 MCP，尚未适配 MCP 的自有 Agent 方案应优先排期

### 5.4 观测平台整合加速

ClickHouse 收购 Langfuse、TrueFoundry 合并 Seldon——独立 LLMOps 工具正在被更大的基础设施平台整合：
- **趋势**：未来 LLM 可观测性将越来越多地内嵌在数据平台（ClickHouse、Snowflake、Databricks）中，而非独立存在
- **建议**：如果已使用 ClickHouse，Langfuse 的集成深度将成为天然优势；如果在评估独立方案，LangSmith 新增 OTel 支持使其不再锁定 LangChain 生态

### 5.5 国内价格战白热化

阿里云"满 200 返 200"（等于 5 折）+ 火山引擎 2.5 折促销 + 百炼最高 100 万元补贴——国内平台正在用激进补贴争夺 API 调用量：
- **建议**：利用当前补贴窗口锁定用量，但避免被短期低价绑定单一平台。火山引擎 2.5 折促销今日（6/30）到期，明日恢复原价
