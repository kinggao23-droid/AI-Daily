## 1. 今日要闻

### 1.1 华为 openPangu 2.0 Pro 即将开源，国产算力生态加速补课

**平台**：华为云盘古

**内容**：6 月 30 日，华为已开源 openPangu-2.0-Flash（920 亿总参数 / 60 亿激活参数 MoE 架构，512K 上下文），同步释出预训练代码、后训练代码及训练算子共 7 大组件。openPangu-2.0-Pro（5050 亿总参数 / 180 亿激活参数）的模型权重与推理代码已确认将于 **7 月内**发布。华为强调该模型针对昇腾芯片做了深度适配，单卡推理吞吐量达同级别开源模型的 **2 倍**。

**影响分析**：这是华为首次将盘古系列大模型以开源方式对外发布，标志着国产算力 + 国产大模型形成完整闭环。对于受合规要求需要「全栈国产化」的政企客户（金融、政务、运营商），openPangu 提供了首个可落地的选择。产品经理需关注 Pro 版本 7 月发布后的实际 benchmark 表现。

**参考链接**：[IT之家报道](https://www.ithome.com/0/963/480.htm) | [华为开源公告](https://www.ithome.com/0/970/466.htm)

### 1.2 AWS Bedrock 发布 Managed Knowledge Base，企业 RAG 门槛再降

**平台**：AWS Bedrock

**内容**：6 月中下旬，AWS 发布 Amazon Bedrock Managed Knowledge Base，提供一站式企业 RAG 管线：
- **原生数据连接器**：支持 S3、SharePoint、Confluence、Google Drive、OneDrive、Web Crawler
- **Smart Parsing**：自动解析 PDF / PPT / HTML 等多格式文档，无需手动预处理
- **Agentic Retriever**：面向复杂多步查询的检索代理，可自动拆分子问题并汇总答案

同期，Bedrock 还新增了 **Grok 4.3（xAI）** 和 **Claude Fable 5（Anthropic）** 两个模型，模型目录已超过 40 个。AgentCore 新增 **Web Search** 工具，支持 Agent 在 AWS 安全环境内调用实时网页搜索。

**影响分析**：Managed Knowledge Base 将企业 RAG 从「拼积木」变成「开箱即用」，直接对标 Azure 的 Foundry IQ 和 Google 的 RAG Cross Corpus Retrieval。对于已在 AWS 生态中的企业客户，迁移成本几乎为零。

**参考链接**：[AWS 官方博客](https://aws.amazon.com/blogs/aws/introducing-amazon-bedrock-managed-knowledge-base-for-faster-more-accurate-enterprise-ai-applications/) | [AWS Weekly Roundup 6/22](https://aws.amazon.com/blogs/aws/aws-weekly-roundup-ny-summit-recap-local-zone-in-hanoi-grok-4-3-in-bedrock-price-reductions-and-more-june-22-2026/)

### 1.3 Snowflake Summit 2026 余波：Cortex Sense 重新定义「Agent 记忆」

**平台**：Snowflake Cortex

**内容**：Snowflake Summit 2026（6 月 1-4 日，旧金山）发布超过 25 项更新，核心亮点：
- **Cortex Sense**（Private Preview）：自动汇集数据定义、业务规则和操作知识，为 Agent 提供企业级上下文。官方称在内部测试中，Agent 准确率从 24% 提升至 **83%**。
- **Cortex Code（CoCo）**：已覆盖 7,100+ 账户，成为 Snowflake 史上增长最快的产品。新增对 AWS Glue、Databricks、Postgres 等外部数据源的支持。
- **Snowflake × Anthropic 战略合作深化**：Claude 驱动 Cortex Code 和 Snowflake Intelligence。
- **AI_TRANSCRIBE 降价 60%**（6 月 1 日生效）。

**影响分析**：Cortex Sense 的核心价值是让 Agent「理解业务语义」而非仅「查数据库」——这是数据平台做 AI 的独特优势。对于数据密集型企业（零售、金融），Snowflake 正在从「数据仓库」升级为「智能数据平台」。

**参考链接**：[Snowflake Summit 全部公告](https://atlan.com/know/snowflake/summit-2026-announcements/) | [Snowflake × Anthropic](https://www.snowflake.com/en/news/press-releases/snowflake-and-anthropic-accelerate-enterprise-ai-adoption-driven-by-rising-demand-for-governed-ai/)

## 5. 对产品经理的启示

### 5.1 企业 RAG 进入「全托管」时代，自建 ROI 需重新评估

AWS Managed Knowledge Base、Azure Foundry IQ、Google RAG Cross Corpus Retrieval 三家几乎同步推出全托管 RAG 方案。如果你的团队正在用 LangChain + Pinecone + 自建 ETL 搭 RAG 管线，现在是时候评估迁移到云原生方案的 ROI——维护成本可能降低 60%+，但需要接受供应商锁定。

**建议**：列出当前 RAG 管线的年度维护人力成本，与三大云的全托管方案做 TCO 对比。

### 5.2 Agent 记忆成为新竞争焦点

Azure 的三层记忆（程序 / 用户 / 会话）、Snowflake 的 Cortex Sense（业务上下文自动汇集）、Google 的 Memory Bank GA——各平台都在解决「Agent 如何记住上下文」的问题。这直接影响 Agent 在多轮对话、跨会话任务中的表现。

**建议**：在选型时重点测试 Agent 的多轮上下文保持能力，而非只看单轮 benchmark 分数。

### 5.3 国产大模型开源加速，私有化部署有了更多选择

华为 openPangu 开源 + 昇腾适配、阿里 Qwen3.7-Max Credits 减半、腾讯 Hy3 快速增长——国产大模型在性能和成本上都在逼近国际前沿。对于有数据主权要求的企业，私有化部署方案正在从「能用」走向「好用」。

**建议**：关注 openPangu 2.0 Pro 7 月发布后的 benchmark 表现，与 Qwen3.7-Max 做横向对比，评估全栈国产化方案的可行性。

### 5.4 推理基础设施暗战升级

Qualcomm 39.2 亿美元收购 Modular、OpenAI 发布自研 Jalapeño 推理芯片——推理层正在从 NVIDIA 单一生态走向多元竞争。中长期来看，推理成本将持续下降，但短期内建议锁定当前供应商的折扣窗口。

**建议**：在签署推理算力长期合同时，加入「最惠价格条款」以对冲未来降价。

### 5.5 可观测性工具分化：选 SaaS 还是自托管？

LangSmith 走 SaaS 路线（SmithDB Rust 重写追求性能极致），Langfuse 走开源自托管路线（ClickHouse 全文搜索），TrueFoundry 走基础设施层路线。三条路线各有取舍：SaaS 省心但数据外传，自托管可控但运维重，基础设施层灵活但集成成本高。

**建议**：根据团队的安全合规要求（是否允许 trace 数据上云）决定路线，再在路线内选产品。
