## 1. 今日要闻

### 🔥 要闻一：DeepSeek V4 正式版官宣 7 月中旬上线，首创「峰谷定价」机制

**平台**：DeepSeek（深度求索）

**具体内容**：DeepSeek 向 API 用户发送邮件，宣布 V4 正式版将于 7 月中旬上线，并同步引入业界首个**峰谷定价机制**：

| 时段 | 时间范围 | 输入价格（缓存未命中） | 输入价格（缓存命中） | 输出价格 |
|------|----------|----------------------|---------------------|---------|
| 高峰 | 每天 9:00-12:00、14:00-18:00 | 6 元/百万 tokens | 0.05 元/百万 tokens | 12 元/百万 tokens |
| 低谷 | 其余时间 | 3 元/百万 tokens | 0.025 元/百万 tokens | 6 元/百万 tokens |

**影响分析**：这是大模型 API 行业首次引入类似电力行业的峰谷定价。对企业用户而言，将批处理任务安排在低谷时段可节省 50% 成本。这一机制可能被其他厂商效仿，成为行业定价新范式。

**参考链接**：[新浪科技报道](https://finance.sina.com.cn/tech/digi/2026-06-29/doc-inifapyq5349057.shtml) | [澎湃新闻](https://m.thepaper.cn/newsDetail_forward_33478426)

### 🔥 要闻二：美团开源万亿参数模型 LongCat-2.0，国产算力全流程训练

**平台**：🆕 新发现平台 — 美团 LongCat

**具体内容**：美团于 6 月 30 日正式发布并开源 LongCat-2.0，核心参数如下：

| 指标 | 数据 |
|------|------|
| 总参数量 | 1.6 万亿（1.6T） |
| 激活参数 | 平均 48B，动态范围 33B~56B |
| 上下文窗口 | 原生支持 100 万 tokens |

**影响分析**：LongCat-2.0 预览版已跻身 OpenRouter 全球调用量前三。这标志着：（1）美团从外卖巨头正式进入基础模型竞赛；（2）国产算力可支撑万亿参数级训练；（3）开源策略将直接冲击 Coding 赛道的闭源模型。

**参考链接**：[美团官方发布](https://www.meituan.com/news/NN260630164005904) | [新华网](http://www.news.cn/tech/20260630/beb4fdc96a5644adbc5fddd10433b801/c.html) | [美团技术团队](https://tech.meituan.com/2026/06/30/LongCat2.0.html)

### 🔥 要闻三：Snowflake Cortex Sense 进入 Private Preview，准确率从 24.1% 飙升至 86.3%

**平台**：Snowflake Cortex AI

**具体内容**：Snowflake 于 7 月中旬开放 Cortex Sense 的 Private Preview。Cortex Sense 是一个「上下文层」服务，它自动汇聚查询历史、对象元数据、BI 仪表盘和 Horizon Catalog 语义视图，为 AI Agent 提供实时业务上下文。

| 指标 | 改进前 | 改进后 |
|------|--------|--------|
| 查询准确率 | 24.1%（基线）/ 47%（CoCo/CoWork） | 86.3% |
| 每次查询成本 | $1.76（frontier agent） | $0.59 |

**影响分析**：Snowflake 正在将自身从「数据仓库」重新定位为「AI Agent 的上下文操作系统」。Cortex Sense 的核心理念——AI 不缺智能，缺的是上下文——与 Databricks CEO 在 DAIS 2026 上的论断一致，说明行业正从「模型竞赛」转向「上下文竞赛」。

**参考链接**：[Snowflake 官方博客](https://www.snowflake.com/en/blog/enterprise-ai-agents-grounded-context/) | [typedef.ai 解析](https://www.typedef.ai/blog/what-is-cortex-sense-snowflakes-runtime-context-layer-explained)

## 4. 新兴平台雷达

### 🆕 美团 LongCat

- **背景**：美团（中国最大的本地生活服务平台）正式进入基础模型赛道
- **亮点**：LongCat-2.0 是业界首个在全国产算力上完成万亿参数训练的模型，OpenRouter 全球调用量前三
- **关注理由**：美团拥有海量真实商业场景数据（外卖、到店、出行），模型聚焦 Agentic Coding，未来可能在垂直场景 Agent 上具备独特优势

### 🆕 DeepSeek DSpark 推理加速框架

- **背景**：DeepSeek 联合北京大学开源的推理加速框架
- **亮点**：半自回归生成 + 置信度调度，吞吐提升 51%~400%
- **关注理由**：可能改变推理层的技术栈格局，与 vLLM 形成互补或竞争

- **背景**：Snowflake 将 Cortex Code 更名为 CoCo、Intelligence 更名为 CoWork，新增 Cortex Sense
- **关注理由**：Snowflake 正从数据仓库向 AI Agent 平台转型，直接与 Databricks Agent Bricks 正面竞争

## 5. 对产品经理的启示

### 启示一：「上下文工程」正在取代「提示词工程」

Snowflake Cortex Sense 和 Databricks Agent Bricks 不约而同地强调同一观点：**AI 不缺智能，缺的是上下文**。对产品经理的建议：

- 在评估 LLMOps 平台时，重点考察其「数据连接」和「上下文注入」能力，而非仅看模型参数
- 企业知识库、BI 报表、查询历史等内部数据的结构化程度，将决定 AI Agent 的实际效果

### 启示二：API 定价正在从「单一费率」走向「动态定价」

DeepSeek V4 的峰谷定价是一个信号。建议：

- 重新审视团队的 API 调用模式，将非实时任务（批量处理、数据分析）迁移到低谷时段
- 在预算规划中引入「时段因子」，而不是简单用 tokens 数量 × 单价估算

### 启示三：国产算力 + 开源模型的生态正在加速形成

一周内，美团 LongCat-2.0（国产五万卡训练）和华为 openPangu-2.0（昇腾原生）相继开源。建议：

- 有国产化合规需求的企业应开始评估这两个模型在自有场景的适配性
- 关注华为 openPangu-2.0 Pro 的 7 月开源进度，505B 参数的 Pro 版本可能是目前参数量最大的国产开源模型

### 启示四：工作流平台（Dify）正在向企业级成熟

Dify v1.8 引入 OAuth 授权、上架 Azure Marketplace，标志着从开发者工具向企业级平台的跨越。建议：

- 正在评估低代码 AI 开发平台的团队，应将 Dify 纳入对比名单（与 Coze、FastGPT 一起评估）
- 关注其即将推出的 Visual RAG Pipeline 功能

### 本周关键选型建议速查

| 需求场景 | 推荐关注 | 理由 |
|---------|---------|------|
| 多模型路由 + 合规治理 | AWS Bedrock / Databricks Agent Bricks | 模型目录最广（40+）/ 统一 AI Gateway 治理 |

| Agent 开发 + 编码 | Claude Sonnet 5（限时价） | 限时 $2/$10，性能接近 Opus 4.8 |
