## 1. 今日要闻

### 🔥 Snowflake Cortex Sense 进入 Private Preview（7月中旬开放）

**平台**：Snowflake Cortex AI

**具体内容**：Snowflake 在 Summit 2026 上发布的 Cortex Sense 正式进入 Private Preview 阶段。Cortex Sense 是一个「上下文层」——它不接触你的实际数据行，只收集元数据（表结构、字段含义、查询历史、使用模式），然后在 AI Agent 回答问题时提供这些背景知识。

**性能数据**：
- 准确率从 24.1% 提升至 86.3%（Snowflake 内部基准）
- 单次查询成本从 $1.76 降至 $0.59（对比 frontier agent）

**影响分析**：这意味着 Snowflake 正在构建「数据即上下文」的护城河——如果你的数据已经在 Snowflake 中，Agent 就能自动理解你的业务语义，无需手动写 prompt。对于已在 Snowflake 生态中的企业，这可能成为不选择其他 LLMOps 平台的理由。

**参考链接**：[Snowflake Blog - Cortex Sense](https://www.snowflake.com/en/blog/enterprise-ai-agents-grounded-context/)

### 🔥 华为 openPangu 2.0 Pro 权重即将于 7 月开源

**平台**：华为云盘古

**具体内容**：继 6 月 30 日开源 openPangu 2.0 Flash（920 亿参数 MoE，激活 60 亿）后，华为宣布 openPangu 2.0 Pro 模型权重和基础推理代码将于 7 月上线开源平台。Pro 版本规格：总参数 5050 亿，激活参数 180 亿，512K 上下文窗口。

**独特之处**：华为不仅开源模型权重，还开源了预训练代码、后训练代码和推理算子——这在国内大厂中属于首次，开源深度超过 Meta Llama 系列。

**影响分析**：对基于昇腾生态的企业（如政务、电信、金融）而言，这是首个可完全自主部署的千亿级国产模型。但目前仅支持昇腾硬件，NVIDIA GPU 用户需等待社区适配。

**参考链接**：[IT之家报道](https://www.ithome.com/0/963/480.htm)

## 4. 新兴平台雷达

### 🆕 Runware — "One API for All AI" 推理平台

- **定位**：统一 API 聚合数十万 AI 模型，主打推理性能优化
- **数据**：已为 20 万+开发者处理超 100 亿次生成，服务 3 亿+终端用户
- **核心优势**：开源模型性价比提升 10 倍，闭源模型节省 10-40%
- **客户**：Wix、Together.ai、Quora、Freepik
- **关注理由**：计划 2026 年底前上架 Hugging Face 全部 200 万+模型，部署 20+ 全球推理 POD

### 🆕 Snowflake CoCo / CoWork 品牌重构

- Cortex Code → **CoCo**（编码助手）
- Snowflake Intelligence → **CoWork**（工作 Agent）
- **意义**：Snowflake 正在从「数据仓库」转型为「Agent 控制平面」，值得持续跟踪

## 5. 对产品经理的启示

### 选型建议

1. **如果你在 Snowflake 生态中**：密切关注 Cortex Sense 的 Private Preview 申请。它的「零标注上下文注入」能力可能大幅降低 Agent 开发门槛，比自建 RAG 管道更省人力。

2. **如果你需要国产自主可控**：华为 openPangu 2.0 Pro 是目前唯一全栈开源（含训练代码）的千亿级国产模型，但绑定昇腾硬件。适合政务、金融、电信等强合规场景。

3. **如果你在做 Agent 应用**：阿里云百炼的 Qwen3.7-Max 5 折促销是窗口期（截至 7/22），适合跑 POC 验证。腾讯混元 Hy3 的 OpenRouter 调用量数据说明其在开发者社区有实际牵引力。

4. **AI 可观测性平台选型**：Braintrust（$8 亿估值）已成为该赛道头部，其「评测+可观测一体化」思路值得关注。如果你是 LangChain 用户，LangSmith 的 SmithDB 升级将显著改善大规模追踪的查询体验。

### 趋势判断

- **「上下文层」成为新战场**：Snowflake Cortex Sense、Databricks Unity Catalog、Atlan 都在争夺「谁能最好地理解企业数据语义」。这比模型能力本身更可能成为企业选型的决定因素。
- **开源深度继续加码**：华为开源训练代码、Meta Llama 系列持续迭代，开源不再只是「给你模型权重」，而是「给你完整复现能力」。
- **vLLM 0.24.0 的撤回提醒**：生产环境推理引擎的版本选择需谨慎，建议锁定 0.23.0 直至 0.24.1 修复发布。
