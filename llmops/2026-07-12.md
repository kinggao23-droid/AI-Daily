## 1. 今日要闻

### 🔥 要闻一：Together AI 完成 8 亿美元 C 轮融资，估值 83 亿美元

**平台：** Together AI（开源模型推理平台）

**具体内容：** 7月1日，Together AI 宣布完成 8 亿美元 C 轮融资，由 Aramco Ventures 领投，Vista Equity Partners、General Catalyst、Emergence Capital、Nvidia、March Capital 等跟投。公司估值从 16 个月前 B 轮的 33 亿美元跃升至 83 亿美元。

**关键数据：**
- 年度预订额突破 11.5 亿美元
- 开源模型使用量同比增长 3 倍
- 客户包括 Cursor、Cognition、Decagon 等头部 AI 公司
- 计划未来 5 年基础设施规模扩大约 50 倍

**影响分析：** 这笔融资表明企业级开源模型推理市场正在爆发式增长。对于正在选型的产品经理来说，Together AI 作为"GPU 推理即服务"的定位越来越清晰——它不直接与 Bedrock/Vertex 竞争，而是成为企业部署开源模型的首选基础设施层。

### 🔥 要闻二：腾讯混元 Hy3 正式发布，MoE 架构 295B 参数

**平台：** 腾讯混元

**具体内容：** 7月6日，腾讯发布混元 Hy3 模型正式版。该模型采用快慢思考融合的 MoE（混合专家）架构，总参数 295B，激活参数仅 21B，支持 256K 上下文长度。

**性能数据：**
- 270 位专家盲测评分：Hy3 均分 2.67/4，优于 GLM5.1（均分 2.51/4）
- 在前端开发、数据与存储、CI/CD 等开发类任务中优势显著
- 已接入 CodeBuddy、元宝、Marvis 等多个产品
- API 已在腾讯云 TokenHub 上线

**影响分析：** 腾讯混元从"跟随者"转变为"有竞争力的参与者"。295B 总参数但仅 21B 激活参数的 MoE 设计意味着推理成本可控，适合大规模企业部署。产品经理应关注其在代码生成和工程辅助方面的差异化定位。

**参考链接：** [新华网报道](http://www.news.cn/tech/20260706/d611426ecba54475b2dd94920e4e3557/c.html)

### 🔥 要闻三：Snowflake Cortex AI 新增 Agent 评估指标体系

**平台：** Snowflake Cortex AI

**具体内容：** Snowflake 在 7 月更新中为 Cortex Agent 引入两个新系统指标：
- **TSA（Tool Selection Accuracy）**：衡量 Agent 编排层是否为给定查询调用了正确的工具
- **TEA（Tool Execution Accuracy）**：衡量每个工具是否接收到合适的输入并返回符合要求的输出

同时新增：
- AI_TRANSLATE 支持最高 10 万 token 的长文档翻译
- 新增 CORTEX_AI_GUARDRAILS_USAGE_VIEW 用于监控 Guardrails 使用情况
- 支持 Resource Budgets 控制 Cortex Search 服务的信用消耗

**影响分析：** Snowflake 正在补齐 Agent 可观测性短板。TSA/TEA 指标让企业可以量化评估 AI Agent 的工具调用质量——这对生产环境中的 Agent 质量把控至关重要。

**参考链接：** [Snowflake 官方文档](https://docs.snowflake.com/en/release-notes/all-release-notes)

## 5. 对产品经理的启示

### 选型建议

1. **Agent 评估成为刚需：** Snowflake 的 TSA/TEA 指标和 Braintrust 的自动标签推断都指向同一趋势——企业需要量化衡量 AI Agent 的"做事质量"，而不仅仅是"回答质量"。建议在选型时将 Agent 可观测性作为必选项评估。

2. **MoE 架构成为国内主流：** 腾讯混元 Hy3（295B/21B）、百度文心（超稀疏 MoE，参数压缩至 1/3）均采用 MoE 架构。好处是推理成本低、可以做到大参数量但推理速度快，产品经理应关注"激活参数量"而非"总参数量"来评估实际推理成本。

3. **开源推理生态加速成熟：** Together AI 年营收超 11.5 亿美元 + vLLM 已迭代到 v0.24.0，意味着企业自建开源模型推理栈的工具链已经非常成熟。如果您的场景对数据隐私要求高、调用量大，自建+开源模型的 TCO 优势可能已经超过调用闭源 API。

4. **Guardrails 覆盖范围扩展到 MCP 工具调用：** TrueFoundry 的 mcp_pre_tool / mcp_post_tool 钩子意味着安全检查不再仅限于 LLM 的输入输出，还覆盖了 Agent 调用外部工具时的数据流。对于金融、医疗等合规场景，这是重要的安全边界扩展。

5. **国内模型价格战持续白热化：** 阿里 Qwen3.7-Max 促销价输入 6 元/百万 token，字节豆包 2.1 Pro 输入 6 元/百万 token，缓存命中仅 1.2 元。建议关注各家的 Token Plan 团队版等订阅式方案，大批量调用时成本可进一步压缩。
