### 1.1 中国《人工智能拟人化互动服务管理暂行办法》今日正式施行，豆包/千问同步下线智能体功能

**事件**：国家网信办等五部门联合出台的《人工智能拟人化互动服务管理暂行办法》于 2026 年 7 月 15 日正式生效。这是全球首部专门针对 AI 情感陪伴、虚拟伴侣等拟人化互动场景的国家级立法。核心要求包括：禁止向未成年人提供虚拟亲属/虚拟伴侣服务；向老年人提供服务须显著提示安全风险；提供智能客服、知识问答、工作助手等不涉及持续性情感互动的服务不受本办法约束。

**平台连锁反应**：字节跳动旗下豆包（Doubao）与阿里通义千问于 7 月 3 日同步公告，将于 7 月 15 日正式下线平台内用户自定义智能体功能。下线后用户无法新建智能体，已创建的智能体也将无法调用运行。豆包建议用户迁移至字节旗下猫箱 App 继续使用智能体功能。

**影响分析**：该法规直接影响 C 端智能体生态，但对 B 端 LLMOps 平台（如百炼、火山引擎企业版）影响有限——企业级工作助手、知识问答类服务明确不在监管范围内。对于出海的中国 LLMOps 平台来说，这一法规可能倒逼其加速 B 端转型。

## 5. 对产品经理的启示

### 5.1 合规先行：中国市场 LLMOps 选型需重视法规适配

今日生效的《人工智能拟人化互动服务管理暂行办法》虽然主要约束 C 端拟人化互动（虚拟伴侣、情感陪伴），但企业在规划 Agent 产品时需明确区分「工作助手/知识问答」（不受约束）与「持续性情感互动」（受严格监管）的边界。建议在产品架构设计阶段就做好合规标注，尤其是面向教育、医疗、养老等场景的 Agent 产品。

### 5.2 Agent 生产就绪成为主战场

AWS Bedrock AgentCore GA、Snowflake Cortex Agent 评估指标（TSA/TEA）、Databricks Genie Agent 模式——三大数据/云平台几乎同时将 Agent 从「实验」推向「生产」。产品经理在做平台选型时，应重点评估：
- **Agent 可观测性**：是否有 Trace、失败分析、意图洞察
- **Agent 安全闭环**：是否内置 Guardrails、prompt injection 检测
- **Agent 性能迭代**：是否支持 A/B 测试、推荐优化

### 5.3 开源推理引擎持续降低成本天花板

vLLM v0.25 的 Streaming Parser Engine 和 Docker 镜像瘦身（-2.5 GB）进一步降低自建推理服务的运维成本。结合文心大模型「预训练成本降至行业 6%」的超稀疏 MoE 架构，2026 年的推理成本曲线仍在加速下行。建议在成本模型中按季度更新基准，避免锁定过长的云平台合约。

### 5.4 模型目录更新节奏加快

GLM-5/5.2、Qwen3.7 系列、DeepSeek V3.2/V4、混元 Hy3 等模型在最近一个月内密集更新。Braintrust 已将 GLM-5.2 设为免配置内置模型。对于运营 LLMOps 平台的团队来说，模型目录的更新周期应从「月度」提速到「双周」，确保企业客户能第一时间使用最新模型。
