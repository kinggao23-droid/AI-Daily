## 1. 今日要闻

### 要闻一：DeepSeek V4 正式版即将发布，首创大模型峰谷定价

**平台**：DeepSeek
**时间**：6月29日公告，7月中旬正式上线（截至7月20日尚未确认正式发布）

DeepSeek V4 正式版进入倒计时，预计本周内落地。正式版基于预览版（4月24日上线并开源）经过两个多月工程调优和企业级功能补齐。

**技术规格**：

| 模型 | 总参数 | 激活参数 | 上下文窗口 | 架构 |
|------|--------|----------|-----------|------|
| V4-Pro | 1.6 万亿 | 490 亿 | 100 万 tokens | 超稀疏 MoE |
| V4-Flash | 2840 亿 | 130 亿 | 100 万 tokens | 超稀疏 MoE |

**定价变化——行业首创峰谷机制**：

- **高峰时段**（每天 9:00-12:00、14:00-18:00 北京时间）：API 价格为平时的 **2 倍**
- **非高峰时段**：维持常规价格
- 这是国内大模型厂商首次引入类似电力行业的「峰谷电价」机制

**关键时间节点**：`deepseek-chat` 和 `deepseek-reasoner` 旧接口将于 **2026年7月24日** 废弃，所有集成必须在此之前迁移至 V4 系列。

**影响分析**：峰谷定价是一把双刃剑——有助于 DeepSeek 平衡算力负载，但增加了企业成本预算的复杂度。对于 Agent 场景（多步推理、高频调用），开发者需重新规划调用时段。建议产品团队评估业务高峰与 API 高峰的重叠度，必要时将非紧急推理任务调度至非高峰时段。

### 要闻二：AWS Bedrock 上线 OpenAI GPT-5.6 三款模型

**平台**：AWS Bedrock
**时间**：2026-07-09 GA

Amazon Bedrock 正式上线 OpenAI GPT-5.6 系列三款模型，这是 AWS 与 OpenAI 合作的最新里程碑。

**模型定位**：

| 模型 | 定位 | 适用场景 | 区域 |
|------|------|---------|------|
| GPT-5.6 Sol | 旗舰推理 | 编程、科研、网络安全 | us-east-1, us-east-2 |
| GPT-5.6 Terra | 日常生产 | 通用任务，成本为 GPT-5.5 的 50% | us-east-1, us-east-2, us-west-2 |
| GPT-5.6 Luna | 高吞吐轻量 | 大批量、低延迟任务 | us-east-1, us-east-2, us-west-2 |

**关键能力**：
- 定价与 OpenAI 官方一致，可计入 AWS 现有消费承诺（EDP/Savings Plan）
- 提示缓存享受 **90% 折扣**
- 硬件级安全：芯片层面零运维人员访问权限
- 区域内数据处理，符合数据驻留合规要求

**影响分析**：Bedrock 目前是唯一同时提供 Claude（Anthropic）、GPT（OpenAI）、Llama（Meta）三大系列模型的云平台。这种"模型超市"策略大幅降低了企业的供应商锁定风险。对于已有 AWS 支出承诺的企业，通过 Bedrock 调用 GPT-5.6 在财务上比直接使用 OpenAI API 更优。

> 参考：[AWS Blog](https://aws.amazon.com/blogs/machine-learning/openai-gpt-5-6-sol-terra-and-luna-are-now-generally-available-on-amazon-bedrock/) · [About Amazon](https://www.aboutamazon.com/news/aws/bedrock-openai-models)

### 要闻三：腾讯混元 Hy3 正式版发布，Agent 能力重点强化

**平台**：腾讯混元
**时间**：2026-07-06

腾讯正式发布混元 Hy3（正式版），相比 4 月 23 日的 preview 版本，在后训练算力规模和数据质量上全面升级，重点强化 Agent 能力。

**核心提升**：
- 复杂推理、指令遵循、代码生成能力进一步提升
- 智能水平「强于同尺寸模型、比肩旗舰模型」
- 定价进一步下降（前代：输入 1 元/百万tokens、输出 4 元/百万tokens）
- 已在 WorkBuddy/CodeBuddy、元宝、Marvis 等多个产品接入
- API 在腾讯云 TokenHub 上线，海外 API 平台陆续接入

**影响分析**：混元 Hy3 的定价优势明显——以远低于 Qwen3.7-Max（输入 12 元、输出 36 元）的价格提供接近旗舰水准的能力。对于预算敏感的中型企业 Agent 场景，混元 Hy3 是国内性价比最高的选项之一。

## 5. 对产品经理的启示

### 5.1 DeepSeek 峰谷定价将成行业趋势——提前规划调用调度

DeepSeek V4 引入的峰谷定价机制可能被其他厂商效仿。**建议**：在产品架构中预留「推理调度层」，将非实时任务（批量分析、离线报告生成）自动安排至非高峰时段，可节省最高 50% API 成本。

### 5.2 「模型超市」时代——云平台比模型更重要

AWS Bedrock 同时提供 Claude + GPT + Llama，Azure Foundry 有 GPT + Claude + Mistral，阿里云百炼集合 Qwen + GLM + 开源模型。**建议**：选型时优先评估「平台治理能力」（身份认证、数据驻留、成本控制、审计日志），而非单一模型性能。模型可以随时切换，平台迁移成本高得多。

### 5.3 Agent 记忆和可观测性成为刚需

AgentPrizm 的记忆平台、Langfuse/LangSmith 的告警功能、Snowflake CoWork Deep Research 的 GA——这些都指向同一个趋势：Agent 正在从「一次性对话」走向「持续运行的自主系统」。**建议**：在 Agent 产品规划中，记忆管理、可观测性（trace/metric/log）、以及审计合规是三个必须同步建设的能力，不能等上线后再补。

### 5.4 国内价格战加剧，差异化要靠场景而非价格

混元 Hy3（输入 1 元/百万tokens）、Qwen3.7-Plus（输入 0.40 元）、GLM-5.2 Fast mode 降价 20%——国内模型定价已接近边际成本。**建议**：如果你的产品依赖国内模型，不要把「便宜」当护城河。转向构建场景壁垒——专属的 RAG 知识库、行业特定的评估流水线、与业务系统的深度集成。

### 5.5 迁移提醒：DeepSeek 旧接口 7/24 下线

使用 `deepseek-chat` 或 `deepseek-reasoner` 端点的集成必须在 **7 月 24 日前** 迁移至 V4 系列。**建议**：本周内完成接口替换和回归测试，避免生产中断。
