## 1. 今日要闻

### 1.1 DeepSeek V4 正式 GA：1M 上下文 + 首创峰谷定价

**平台**：DeepSeek
**时间**：2026-07-20 GA（预览版自 4 月 24 日开放）

DeepSeek V4 于 7 月 20 日正式结束预览期进入 GA。GA 版本在预览版基础上新增：
- **Agentic 能力**：支持多步 Agent 编排和工具调用
- **数学推理增强**：数学基准测试分数显著提升
- **代码生成改进**：专项优化代码生成质量
- **上下文窗口**：1M token（百万级长文本）

**定价变化（重大）**：DeepSeek 首次引入峰谷定价（Peak/Off-Peak Pricing）：
- **峰时**（每日 9:00-12:00, 14:00-18:00）：API 价格为非峰时的 **2 倍**
- 模型 ID：`deepseek-v4-pro-202606`（旗舰）、`deepseek-v4-flash-202605`（轻量）

**影响分析**：峰谷定价是 LLM API 市场的新模式——类似电力行业的分时计费。对于可以灵活调度推理任务的企业（如批量数据处理、离线分析），可以通过在非峰时段调用大幅降低成本。但这也增加了成本预估的复杂度，产品经理需要评估业务场景的时间分布。

**参考**：[TechNode 报道](https://technode.com/2026/06/30/deepseek-to-launch-v4-in-mid-july-with-new-peak-time-api-pricing/) | [DeepSeek API Docs](https://api-docs.deepseek.com/news/news260424/)

### 1.2 腾讯混元 Hy3 正式版发布：全球开源，Apache 2.0 许可

**平台**：腾讯混元
**时间**：2026-07-06 正式发布

腾讯于 7 月 6 日正式发布混元 Hy3 基座模型，是 4 月 23 日预览版的正式迭代：

| 参数 | 规格 |
|------|------|
| 架构 | MoE（混合专家） |
| 总参数 | 295B |
| 激活参数 | 21B |
| 上下文窗口 | 256K |
| 许可证 | Apache 2.0（全球免费商用） |

关键改进：
- **Agent 能力突出**：强化智能体多步推理和工具调用
- **幻觉大幅降低**：相比预览版显著减少事实错误
- **生态集成**：与微信生态、数字人、短视频深度打通
- **许可升级**：从预览版的限制性许可（排除欧盟、英国、韩国）改为 Apache 2.0，全球无限制

模型权重已在 GitHub、HuggingFace、ModelScope 全面开源。

**影响分析**：混元 Hy3 的 Apache 2.0 开源策略是对 DeepSeek、Llama 等开源模型的直接竞争。295B 总参数 / 21B 激活参数的 MoE 架构在推理效率上具有优势。对于需要在国内部署开源大模型的企业，混元 Hy3 是继 Qwen 和 DeepSeek 之后的又一重要选项。

**参考**：[财新报道](https://companies.caixin.com/m/2026-07-06/102461428.html) | [新浪财经](https://finance.sina.com.cn/stock/t/2026-07-06/doc-inifwfpu1887689.shtml)

### 1.3 Snowflake Cowork Deep Research GA + Cortex Sense 私有预览

**平台**：Snowflake
**时间**：2026 年 7 月（Summit 2026 后持续发布）

Snowflake 在 7 月宣布多项 AI 功能进入 GA 或预览：
- **Cowork Deep Research**（GA）：个人工作 Agent，可跨企业数据源进行多步骤研究，自动综合分析并交付结论
- **Cowork Skills / MCP 连接器 / iOS 移动端**（GA）：技能系统和移动端全面上线
- **Cortex Sense**（私有预览，7 月中旬）：利用元数据、查询历史和语义视图提升 AI Agent 回答准确性，适用于 CoWork 和 CoCo
- **Cortex Code 扩展数据源**：新增 AWS Glue、Databricks、Postgres 连接支持，并通过 MCP 和 Agent Communications Protocol 对接外部 AI 系统

**影响分析**：Snowflake 正加速从「数据仓库」向「AI 控制平面」转型。Cowork Deep Research 的 GA 意味着企业用户可以直接在 Snowflake 中进行复杂的数据分析，无需跳转到第三方工具。Cortex Code 对 Databricks 的支持也体现了 Snowflake 主动打通竞品生态的开放策略。

**参考**：[Snowflake AI Pulse July 2026](https://www.snowflake.com/en/ai-pulse/july-2026/) | [Snowflake Summit 2026 回顾](https://select.dev/posts/snowflake-summit-2026-product-announcement-recap)

### 🆕 Crunchbase MCP — 私有市场情报直通 LLM

**发布日期**：2026-07-21
**核心能力**：Crunchbase 发布 MCP（Model Context Protocol）服务器，将其私有市场数据直接注入 LLM 回答：
- 覆盖 **3900 万+** 实时私有市场信号、**790 个** 公司数据字段、**1500 万+** 预测数据
- 融资预测准确率 **84%**

**对产品经理的意义**：这代表了「数据 MCP 化」的趋势——专业数据提供商通过 MCP 标准接口将数据直接输送给 AI Agent，而非传统的 API 或仪表板模式。值得关注类似模式在企业数据领域的复制。

## 5. 对产品经理的启示

### 5.1 峰谷定价值得产品规划提前考虑

DeepSeek 率先引入的峰谷定价模式可能被更多厂商效仿。**建议**：在产品架构中预留「任务调度层」，将非实时任务（报告生成、数据分析、内容批量处理）路由至非峰时段，可节省高达 50% 的推理成本。

### 5.2 MoE 开源模型格局进一步丰富

腾讯混元 Hy3（295B/21B MoE, Apache 2.0）加入 Qwen-3 和 DeepSeek V4 的开源阵营。**建议**：企业私有化部署评估应将混元 Hy3 纳入候选列表，特别是需要微信生态集成或数字人场景的团队。Apache 2.0 许可比 Llama 的社区许可更友好。

### 5.3 「数据 MCP 化」是新的竞争维度

Crunchbase MCP 的发布预示着一个趋势：专业数据源将通过 MCP 标准协议直接供给 AI Agent，取代传统 SaaS 仪表板。**建议**：评估自身产品是否有数据资产可以「MCP 化」对外开放，抢占 Agent 生态中的数据节点位置。

### 5.4 LLM 可观测性工具迎来架构代际更替

Langfuse v4 迁移至 ClickHouse、LangSmith 重构评估框架——两大 LLM 可观测平台同期进行架构升级。**建议**：如果团队正在选型，建议等 Langfuse v4 稳定版发布后再做最终决策；如已在用 v3，提前规划 ClickHouse 迁移所需的基础设施准备。

### 5.5 Snowflake 的「AI 控制平面」野心值得警惕

Snowflake Cowork Deep Research GA 标志着数据仓库厂商正式进入 AI Agent 市场。对于已经在 Snowflake 上存储数据的企业，Cowork 提供了「零迁移成本」的 AI 分析方案。**建议**：如果你的用户数据在 Snowflake 上，Cowork 可能比独立的 LLMOps 平台更有吸引力——它省去了数据打通环节。
