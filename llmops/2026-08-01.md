## 1. 今日要闻

### 要闻一：AWS Bedrock Agents Classic 正式进入维护模式——AgentCore 成为唯一选择

**平台**：AWS Bedrock

**具体更新**：自 2026 年 7 月 30 日起，Amazon Bedrock Agents（2023 年 11 月发布的初代 Agent 框架）正式更名为 **Bedrock Agents Classic**，不再接受新客户注册。所有新建 Agent 工作负载必须使用 **Amazon Bedrock AgentCore**（2026 年 4 月底 GA）。现有客户的工作负载不受影响，但模型目录已冻结——7 月 30 日之后新发布的模型将仅在 AgentCore 中可用。

**关键区别**：
- **Agents Classic**：单 Agent 框架，基础工具调用，内置 RAG
- **AgentCore**：多 Agent 系统架构，支持 Agent 间共享记忆、任务委派、统一网关路由，自带 7 月 20 日 GA 的统一可观测性（traces + logs 合并到单一日志组）

**影响分析**：这对正在评估 AWS 的企业客户是明确信号——不要再基于 Agents Classic 做技术选型。AgentCore 是完全重新架构的产品，不是简单改名。已在使用 Agents Classic 的团队需要启动迁移规划，AWS 官方文档已提供迁移指南。

### 要闻二：OpenAI GPT-5.6 全系列（Sol / Terra / Luna）已在 AWS Bedrock GA

**平台**：AWS Bedrock / OpenAI

**具体更新**：7 月 9 日起，GPT-5.6 的三个变体已在 Amazon Bedrock 全面可用（GA）。这是继 6 月 GPT-5.5 / GPT-5.4 / Codex 上线后的又一次扩充。

**三款模型定位**：
| 模型 | 定位 | 核心优势 |
|------|------|----------|
| GPT-5.6 Sol | 高级推理 | 编程、科研、网络安全领域的深度推理 |
| GPT-5.6 Terra | 日常生产 | 成本为 GPT-5.5 的 50%，面向通用生产任务 |
| GPT-5.6 Luna | 高吞吐轻量 | 快速、低价、面向大批量请求场景 |

**关键细节**：
- 定价与 OpenAI 自有 API 一致，可抵扣现有 AWS 承诺消费额度（EDP）
- 支持 Prompt Caching，缓存命中享 90% 折扣
- 在区域内处理数据，芯片级硬件安全隔离，零操作员访问

**影响分析**：AWS Bedrock 从"Anthropic + Meta 为主"正式转向"全模型超市"策略。企业客户现在可以在同一个 Bedrock 控制面板中同时使用 Claude Opus 4.8、GPT-5.6 Sol、Llama 4 Maverick，大幅降低多模型管理的运维复杂度。对 Azure AI Foundry 的"OpenAI 独家"优势构成直接冲击。

**参考链接**：

- [About Amazon 详解](https://www.aboutamazon.com/news/aws/bedrock-openai-models)

### 要闻三：腾讯混元 Hy-3 正式版发布——Agent 能力为核心卖点

**平台**：腾讯混元

**具体更新**：腾讯于 7 月 6 日正式发布混元 Hy-3 基座模型正式版（此前 4 月 23 日发布的是 preview 版）。正式版在后训练阶段投入了更大算力，并提升了数据质量和多样性。

**核心参数**：
- 架构：MoE（混合专家），总参数 295B，激活参数 21B
- 上下文窗口：256K tokens
- 开源协议：Apache-2.0，全球免费商用
- 重点能力：Agent 智能体能力显著增强，幻觉率大幅降低

**生态集成**：与微信生态、数字人、短视频场景深度打通，元宝（腾讯 C 端 AI 助手）已接入，同步上线免费 Agent 功能。

**影响分析**：腾讯以"免费开源 + 生态绑定"的策略切入，295B 参数规模在国产开源模型中处于前列。对 Dify / FastGPT 等开源平台生态有正面影响（可直接集成），对字节豆包和阿里通义在 C 端的流量形成竞争。

## 5. 对产品经理的启示

### 5.1 AWS Agent 技术栈选型：立即迁移到 AgentCore

如果你的企业正在评估或已使用 AWS Bedrock Agents，**现在必须基于 AgentCore 做技术选型**。Agents Classic 已停止接纳新客户，模型目录已冻结。AgentCore 是一次完全重构，支持多 Agent 协作、共享记忆和统一网关——这不是可以推迟的升级，而是平台迁移。

### 5.2 多云模型策略：Bedrock 正在消解 Azure 的 OpenAI 独占优势

GPT-5.6 系列在 Bedrock GA 后，Azure 作为"唯一能用 OpenAI 模型的云平台"的护城河正在瓦解。如果你的企业已有大额 AWS 合同，可以在不增加供应商的情况下同时使用 Claude、GPT-5.6 和 Llama 4。建议重新评估是否仍需维护 Azure AI Foundry 的并行部署。

### 5.3 国产模型性价比窗口期

阿里 Qwen3.7-Max（成本 1/25 GPT-5.5，SWE-bench 72.3%）和腾讯混元 Hy-3（295B 参数，Apache-2.0 免费商用）为国内企业提供了极具吸引力的选项。如果你的业务场景不要求最顶尖模型能力，这两款模型在成本效率上有显著优势。建议在内部 PoC 中加入这两个选项进行对比测试。

### 5.4 可观测性已成标配——选型关注点转向部署模式

Langfuse 和 LangSmith 在 2026 年 7 月均推出了阈值告警功能，功能趋同。选型差异正在从"谁的功能更多"转向"开源自托管（Langfuse/ClickHouse）vs 托管 SaaS（LangSmith）"的部署模式之争。如果你的企业对数据主权有要求，Langfuse 被 ClickHouse 收购后的工程投入值得重新评估。

### 5.5 Agent 身份治理将成为下一个合规要求

Snowflake 的 SERVICE_AGENT 用户身份 GA 和 Cortex AI Gateway 的 MCP 治理能力，预示着"AI Agent 需要独立身份和审计轨迹"正在从最佳实践变成合规要求。如果你的产品涉及 Agent 访问企业数据，建议提前规划 Agent 身份管理方案。
