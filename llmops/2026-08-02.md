# LLMOps 竞品情报日报

**日期**：2026-08-02（周日）
**概要**：本日无各平台官方重大发布公告，但过去 48 小时内 DeepSeek V4-Flash-0731 正式进入公测是最值得关注的事件，对企业 LLMOps 平台的模型选型和成本结构产生直接影响。以下综合近 1-3 日动态整理。

## 1. 今日要闻

### 1.1 DeepSeek V4-Flash-0731 公测上线，Agent 能力大幅跃升

- **平台**：DeepSeek（可通过 AWS Bedrock、各 LLMOps 网关接入）
- **时间**：2026-07-31
- **具体内容**：DeepSeek 正式发布 V4-Flash-0731 公测版。模型参数规模为 284B 总参 / 13B 激活（MoE 架构），上下文窗口 100 万 token，最大输出 38.4 万 token。原生支持 OpenAI Responses API 格式，适配 Codex 场景。
- **性能数据**：
  - Terminal Bench 2.1：82.7 分（较 Preview 版 61.8 提升 20.9 分）
  - DeepSWE：54.4 分（较 Preview 版 7.3 提升 47.1 分）
  - 官方称 Agent 能力"far exceed"V4-Pro-Preview
- **定价**：输入 $0.14/百万 token，输出 $0.28/百万 token，缓存命中仅 $0.0028/百万 token——与 Preview 版保持一致，未涨价
- **影响分析**：该定价仅为 Claude Sonnet 5 的 1/14（Sonnet 5: $2/$10）、GPT-5.6 Luna 的 1/4（Luna: $0.20/$1.20），而 Agent 性能已逼近旗舰级。对于企业 LLMOps 平台而言，这意味着"低成本 + 强 Agent"的模型选项正式可用于生产环境，将加速模型路由（routing）和降本策略的落地。
- **参考**：[MarkTechPost 报道](https://www.marktechpost.com/2026/07/31/deepseek-upgrades-deepseek-v4-flash-0731-with-major-agentic-and-coding-gains/) | [XenoSpectrum 定价分析](https://xenospectrum.com/en/deepseek-v4-flash-0731-pricing/) | [Hugging Face 模型页](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-0731)

### 1.2 阿里云通义千问 Qwen3.8-Max-Preview 进入公开预览

- **平台**：阿里云百炼
- **时间**：2026-07-19 发布，目前持续预览中
- **具体内容**：Qwen3.8-Max-Preview 是通义千问系列参数规模最大的旗舰预览模型，总参数 2.4 万亿（2.4T），支持全模态（文本、图像、短视频、多格式文档）的解析和生成。上下文窗口约 98 万 token，最大输出 13.1 万 token。
- **定价**：预览期间通过 Token Plan 订阅以标准价 10% 供应；夜间折扣进一步降至约标准价的 0.2%。Lite 套餐 $6/周、Pro 套餐 $68/月（4 万 credits）
- **影响分析**：阿里以"先体验后定价"的策略抢占开发者心智，但尚未公布完整基准测试表和开源权重发布时间。对国内企业选型而言，需关注正式版定价和 SLA 承诺。
- **参考**：[eesel AI 评测](https://www.eesel.ai/blog/qwen38-max-review) | [BenchLM 模型页](https://benchlm.ai/models/qwen3-8-max-preview)

### 1.3 Langfuse 持续高频迭代，v3.224.0 已发布

- **平台**：Langfuse（开源 LLM 可观测性平台）
- **时间**：2026-07-22（v3.224.0）
- **具体内容**：新增布尔型评分组件（Boolean Score Widgets）和监控器，Trace 观测数据以字节流方式传输提升性能；MCP 评分读取工具迁移至 Scores v3 接口；ClickHouse 表新增 created_at 跳跃索引加速查询。
- **影响分析**：Langfuse 保持每日级别的发布频率，持续拉开与 LangSmith 在开源自托管场景下的差距。布尔评分组件对于 Agent 场景下的"通过/失败"质量门控特别实用。
- **参考**：[Langfuse Changelog](https://langfuse.com/changelog) | [releases.sh 追踪](https://releases.sh/langfuse)

## 4. 新兴平台雷达

### DeepSeek 作为"平台级"力量的崛起

DeepSeek 虽然不是传统意义上的 LLMOps 平台，但 V4-Flash-0731 的发布标志着一个重要转折：一个开源模型提供商正在以接近零的 API 价格提供旗舰级 Agent 能力。这迫使所有 LLMOps 平台的模型网关和路由策略重新评估成本模型。

### Kimi K3（月之暗面）

Kimi K3 在 Arena Frontend Code 排名第一，Artificial Analysis Intelligence Index 排名第四，定价 $3/$15 每百万 token，是西方旗舰模型的 1/3 到 1/5。作为国产模型的出海先锋，值得 LLMOps 平台纳入模型路由选项。

### Snowflake Cortex Sense（AI Agent 上下文引擎）

6 月发布的 Cortex Sense 将数据、业务定义和运营知识整合为 AI Agent 的上下文层，是"数据平台 → Agent 平台"转型的典型案例。

## 5. 对产品经理的启示

### 5.1 模型路由策略必须纳入 DeepSeek V4-Flash

DeepSeek V4-Flash-0731 以 $0.14/$0.28 的价格提供接近旗舰级的 Agent 能力（Terminal Bench 82.7），企业 LLMOps 平台应立即评估将其纳入模型路由策略。**具体建议**：在非安全敏感的 Agent 编码任务中默认使用 V4-Flash，仅在需要最高质量时升级到 Claude Opus 或 GPT-5 系列，预计可降低 70-90% 的推理成本。

### 5.2 阿里 Qwen3.8-Max 的"预览期低价"是双刃剑

预览期 10% 定价极具吸引力，但正式版定价、SLA 和数据合规承诺尚未明确。**具体建议**：可在内部测试环境中试用，但不建议在生产环境中建立对预览期定价的依赖。等待正式版发布后再做选型决策。

### 5.3 可观测性平台选型：LangSmith vs Langfuse 的分水岭更加清晰

LangSmith 通过 SmithDB 在云端查询性能上建立了 15 倍优势，但自托管版尚未跟进。Langfuse 在开源自托管、MCP 集成、社区活跃度上保持领先。**具体建议**：如果你的企业需要数据本地化部署，Langfuse 仍是首选；如果接受 SaaS 且追求极致查询性能，LangSmith Cloud 正在拉开差距。

### 5.4 Databricks 和 Snowflake 的"Agent 治理"竞赛值得密切跟踪

两家数据平台都在从"数据平台"向"Agent 运行平台"转型。Databricks 的 Unity AI Gateway（统一治理层）和 Snowflake 的 AI Agent Identity（加密身份 + RBAC）代表了两种不同的治理哲学。**具体建议**：如果企业已深度使用 Databricks/Snowflake 的数据栈，优先在同一生态内构建 Agent 治理能力，避免引入额外的 LLMOps 平台增加集成复杂度。

### 5.5 vLLM v0.26 撤回事件的警示

vLLM v0.26.0 因张量并行 bug 被撤回（yanked），提醒我们开源推理引擎在生产环境中需要额外的稳定性验证。**具体建议**：生产环境锁定 v0.25.0，建立灰度发布流程，不要在第一时间跟进最新版本。
