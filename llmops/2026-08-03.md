# LLMOps 竞品情报日报

**日期**：2026-08-03（周一）
**概要**：周末期间无各平台官方重大产品发布，但近 48 小时内有三个值得关注的动态：AWS Bedrock 上 GPT-5.6 Terra/Luna 大幅降价正式生效、Microsoft Foundry Assistants API 退役倒计时进入最后 23 天、以及 AI 推理算力成本出现结构性上涨信号。以下综合近 1-3 日动态整理。

---

## 1. 今日要闻

### 1.1 AWS Bedrock 上 GPT-5.6 Terra 降价 20%、Luna 降价 80%，已正式生效

- **平台**：AWS Bedrock / OpenAI
- **时间**：2026-07-30 生效，Bedrock 同步跟进
- **具体内容**：OpenAI 在 GPT-5.6 发布仅三周后（7 月 10 日发布）即进行首轮降价。Sol 旗舰版价格不变，Terra 中端版和 Luna 轻量版分别下调 20% 和 80%。降价后最新定价（每百万 token）：
  - **Sol**（旗舰推理）：$5.00 输入 / $30.00 输出（未变）
  - **Terra**（日常生产）：$2.00 输入 / $12.00 输出（降前 $2.50/$15.00）
  - **Luna**（高吞吐量）：$0.20 输入 / $1.20 输出（降前 $1.00/$6.00）
  - 缓存命中折扣：90%
- **影响分析**：Luna 降价后定价与 DeepSeek V4-Flash（$0.14/$0.28）同一数量级，但仍贵约 4 倍。对 LLMOps 平台模型路由而言，Luna 成为"在 AWS 生态内替代 Haiku/Flash 级模型"的有力选项，企业无需跨平台调用 DeepSeek 即可获得低成本推理。Terra 定价与 Claude Sonnet 5 持平（$2/$10 促销价 vs $2/$12），竞争更加白热化。
- **参考**：[Finout GPT-5.6 定价分析](https://www.finout.io/blog/gpt-5.6-pricing-2026-sol-terra-and-luna-tiers-explained) | [AWS 官方博客](https://aws.amazon.com/blogs/machine-learning/openai-gpt-5-6-sol-terra-and-luna-are-now-generally-available-on-amazon-bedrock/) | [eesel AI 定价解析](https://www.eesel.ai/blog/gpt-5-6-pricing)

### 1.2 Microsoft Foundry Assistants API 退役倒计时：8 月 26 日强制下线

- **平台**：Microsoft Foundry（原 Azure AI Foundry）
- **时间**：2026-08-26 硬性截止
- **具体内容**：Microsoft 在年初将 Azure AI Foundry 更名为 Microsoft Foundry，同时宣布 Assistants API 进入退役周期。8 月 26 日之后，所有仍在调用 Assistants API 的生产代码将停止工作，Microsoft 以 Foundry Agent Service 作为替代方案。此外，Claude Fable 5 已在 Microsoft Foundry 中上线可用。
- **影响分析**：距离退役仅剩 23 天，仍在使用 Assistants API 的企业需立即启动迁移。Foundry Agent Service 提供运行时、工具调用、记忆、grounding、可观测性和治理的完整栈，但迁移成本不低——API 接口和会话管理模型完全不同。
- **参考**：[Microsoft Foundry 官方博客](https://azure.microsoft.com/en-us/blog/product/microsoft-foundry/) | [Schneider IT 更名分析](https://www.schneider.im/microsoft-foundry-the-new-name-for-azure-ai-foundry/) | [InfoQ Foundry Agent 报道](https://www.infoq.com/news/2026/06/microsoft-foundry-agents/)

### 1.3 AI 推理算力成本出现结构性上涨信号

- **来源**：多家分析机构综合
- **具体内容**：尽管模型 API 价格持续下降，底层算力成本却在反向上涨。GPU 现货价格较 2 月低点已上涨 40%+。据报道 Google 每月向 SpaceX 支付约 $9 亿用于 11 万块 GPU 的部署。Anthropic 预计 2026 年年化收入达 $1000-1500 亿，推理利润率从 2025 年的 40% 提升至 80%+（Fable 推理效率驱动），但行业整体算力需求增速（AI 实验室收入增长）远超算力建设速度（约 3 倍/年），意味着未来 12-18 个月推理成本可能上涨 10-15 倍。
- **影响分析**：这是一个"剪刀差"信号——API 价格在降，但底层资源在涨。对 LLMOps 平台产品经理的警示：当前的低价可能不可持续，企业应在成本模型中预留算力价格上涨的 buffer，并加速评估自部署（vLLM + 自有 GPU）方案作为对冲。
- **参考**：[AI Weekly 8 月 2 日报道](https://aiweekly.co/ai-news-today) | [LLM Stats 8 月更新](https://llm-stats.com/llm-updates)

## 4. 新兴平台雷达

### 🆕 Ruflo — 开源 AI Agent 平台曝出最高危漏洞

Ruflo 是一个开源 AI Agent 平台，近日被披露一个最高严重性漏洞 CVE-2026-59726，影响其 233 个工具接口。该漏洞允许未授权访问 Agent 工具执行能力。虽然 Ruflo 本身市场份额有限，但这一事件对所有 LLMOps 平台敲响了安全警钟：Agent 工具链的权限管理和沙箱隔离是企业级部署的硬性要求。

### 🆕 Laminar — LLM 可观测性新挑战者

Laminar 在 2026 年初的对比评测中开始与 Langfuse 和 LangSmith 并列出现，定位为"更轻量的 LLM 可观测性方案"。值得持续关注其功能差异化和社区增长。

### AWS Bedrock 新控制台体验

Bedrock 推出全新控制台，支持模型并排对比、项目化管理、代码片段自动补全。控制台优化了对 OpenAI Responses API 和 Anthropic Messages API 的双协议支持，标志着 Bedrock 从"模型市场"向"开发平台"的定位升级。

## 5. 对产品经理的启示

### 5.1 GPT-5.6 Luna 降价 80% 改变了低成本层的竞争格局

Luna 降至 $0.20/$1.20 后，在 AWS 生态内首次出现了可与 DeepSeek V4-Flash 同量级竞争的低价选项。**具体建议**：对于已深度绑定 AWS 的企业，Luna 可替代部分 DeepSeek 调用，避免跨平台数据流转的合规风险。但在纯成本维度，DeepSeek V4-Flash 仍便宜 4 倍，适合对数据出境不敏感的场景。

### 5.2 Microsoft Foundry Assistants API 退役需立即行动

8 月 26 日硬性截止，仅剩 23 天。**具体建议**：本周应完成 Assistants API 调用的代码审计，识别所有依赖点；下周启动向 Foundry Agent Service 的迁移；优先迁移生产环境的高频调用链路。Foundry Agent Service 的会话管理模型与 Assistants API 完全不同，预估迁移周期 1-2 周。

### 5.3 算力成本"剪刀差"要求重新审视 TCO 模型

API 价格在降，但 GPU 现货价格在涨（+40%）。当前的低价窗口可能是暂时的。**具体建议**：(1) 在 TCO 模型中加入算力价格年化上涨 50-100% 的压力测试场景；(2) 加速评估 vLLM + 自有/租赁 GPU 的自部署方案作为成本对冲；(3) 优先锁定年度合同价格而非按量计费。

### 5.4 Agent 平台的安全治理成为选型硬指标

Ruflo 漏洞事件 + AWS Bedrock Agents Classic 退役 + Microsoft Assistants API 退役，三个信号叠加说明：Agent 平台的安全性和 API 稳定性是企业选型的关键维度。**具体建议**：在评估 Agent 平台时，将"工具调用的权限隔离机制"、"API 生命周期管理承诺"、"安全漏洞响应 SLA"列为必选评估项。

### 5.5 国内模型定价战进入"常态化低价"阶段

2026 上半年国内厂商 6 次下调 API 价格、3 次宣布永久降价，DeepSeek V4-Pro 输出价已降至 ~6 元/百万 token。**具体建议**：国内企业在选型时，价格已不再是核心差异化因素，应转向关注模型在特定业务场景（如金融合规、能源调度、电信客服）的效果基准测试结果，以及平台的企业级功能（审计、权限、SLA）成熟度。
