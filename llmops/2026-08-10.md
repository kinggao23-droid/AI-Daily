### 🔥 要闻一：阿里 Qwen3.8-Max 开源权重预计本周（8月10日当周）释放，首次开源 Max 级模型

**平台**：阿里云百炼（通义千问/Qwen）

**具体内容**：8 月 3 日发布的 Qwen3.8-Max 将成为 Qwen 系列首个开源的 Max 级模型。阿里确认开源权重将于 **8 月 10 日当周** 发布。模型核心规格：

- **上下文窗口**：100 万 token
- **原生多模态**：支持文本、图片、视频输入
- **性能基准**：OSWorld-Verified 得分 86.1，超越 GPT-5.6 Sol Max（83.2）、Claude Fable 5（85.0）、Gemini 3.1 Pro（76.2）
- **API 定价**：$2.00/百万输入 token，$6.00/百万输出 token，缓存命中 $0.25/百万 token

**影响分析**：这是开源模型领域的标志性事件——此前 Max 级参数规模（万亿级 MoE）的模型从未开源。一旦权重发布，企业可在私有基础设施上部署万亿参数级模型，无需支付 API 费用。对于已具备 GPU 集群的企业（需要多节点 A100/H100 部署），这将直接改变自建 vs 购买 API 的成本测算。同时，与 DeepSeek V4-Flash（$0.14/$0.28）相比，Qwen3.8-Max 的 API 定价高出约 14-21 倍，但在复杂任务上的性能领先明显，形成"旗舰性能 vs 极致性价比"的分层格局。

### 🔥 要闻三：Anthropic 发布 Claude Code 自托管环境公测版，企业级 Agent 可运行在自有基础设施

**平台**：Anthropic Claude

**具体内容**：8 月 6 日，Anthropic 正式推出 Claude Code 自托管环境（Self-Hosted Environments）公测版，面向 Team 和 Enterprise 计划用户。核心特性：
- **本地运行**：Claude Code 会话运行在企业自有网络内部，可访问内网服务、私有工具链和安全控制
- **数据安全**：代码检出、构建产物、密钥和所有会话文件留在企业自管机器上
- **运维要求**：需要平台/DevEx 团队负责 Runner 镜像维护、更新和编排器运行
- **管理增强**：同步推出管理员分析面板、模型级权限控制和费用预警功能

**影响分析**：这标志着 Anthropic 正式进军"企业自托管 AI Agent"赛道。对于受监管行业（金融、医疗、国防等），数据不出内网是采用 AI Coding Agent 的前提条件。此举直接对标 GitHub Copilot Enterprise 的私有化部署能力，也给 Azure AI Foundry 和 AWS Bedrock 的托管 Agent 服务带来压力。但需注意，Anthropic 明确建议"大多数企业使用托管版本"，自托管仅推荐给有严格合规需求的团队。
